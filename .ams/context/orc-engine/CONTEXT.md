# OrcEngine（触发器引擎原型）

面向卡牌游戏（Godot C#）的后端逻辑引擎原型（.NET 8 / C# 12），核心为触发器系统；S1「核心运行时」先行落地 Lifetime/Ref/Entity/Context/ContextView 体系、异常与最小触发器壳。

## Language

**触发器（Trigger）**：
逻辑的起点；一个触发器只有一个 ContextView，其产出的 ctx 被全部事件共用（解决"引用隐式依赖"的关键设计）。
_Avoid_: 包装器、规则

**ContextView（转接器）**：
触发器唯一的数据契约——声明式受限视图，按 [Read]/[Mutate]/[Optional] 裁剪对数据载体的访问权限。
_Avoid_: 视图模型、ViewModel

**Context（ctx）**：
一次结算的数据载体；S2 增加 Stop/Interrupt 停止语义（链标识判定不落地）。
_Avoid_: 执行环境、运行上下文

**Data（数据载体）**：
Context 持有的唯一字典（Dictionary<string, object?>）；视图绑定的唯一数据源，跨执行存续、由 Context 独占。
_Avoid_: 载荷、State、数据包

**Ref / Lifetime**：
安全引用与生命周期令牌；Ref 仅由持有者内部创建（如 Entity.Ref），访问失效引用抛 StaleReferenceException。
_Avoid_: 弱引用、句柄

**权限矩阵**：
视图属性访问规则：[Read] 只读（写拒绝）、[Mutate] 可增改、[Optional] 缺省读 default、无有效特性一律拒绝（PermissionDeniedException）。
_Avoid_: ACL、访问表

**声明即工作**：
视图作者只写"类 + [ContextView] + 特性属性"（无转发/胶水），拦截由框架统一提供。
_Avoid_: 约定优于配置

**Seal（会话封印）**：
视图实例"单次执行会话"的终结标记；幂等、不放松权限矩阵、不影响数据载体可访问性。
_Avoid_: Dispose、关闭、冻结

**共享而非拷贝**：
同一 Context 被多次执行共用同一 Data 载体（Bind 直连）；Context 创建时对传入字典做一次拷贝后独占。
_Avoid_: 复制、快照

**事件（S2 落地）**：
触发器内部的原子逻辑（handler），可改写 ctx 数据；同一触发器的所有事件共用同一视图与 ctx。
_Avoid_: 回调、动作

**触发入口（InvokeAsync 重载族）**：
触发器执行入口的三种形态称谓：统一入口（引擎引用＋数据字典＋取消令牌，框架提供的规范收敛点，返回事件流）、具名重载（作者侧书写、经转接汇入统一入口）、字典透传（零加工直入统一入口）；三者为同一方法名的重载。
_Avoid_: 触发函数、调用接口

**转接（Translate）**：
作者视图类上的手写静态方法，把具名调用参数写入数据字典供统一入口创建 ctx；框架不建立强制契约类型、不隐式调用。
_Avoid_: 参数适配、包装

**Band（区段）**：
以 C# 枚举类型定义的区段方案——成员名＝区段名、成员值＝自然数；未声明时用框架内置默认枚举（仅 default=0），声明后成员即区段；两者二选一（专门枚举下注册必须显式携带成员，不存在回落 default）；方案经构造面显式声明、不得隐式推断。
_Avoid_: 优先级组、槽位

**Kind（激活类型）**：
触发器的主动/被动标识，默认主动、运行期可读；S3 起与挂载条件关联（Passive+hook 非空方可挂载）。
_Avoid_: 类型、模式

**执行链（嵌套链）**：
嵌套触发的逻辑关联结构——各次执行各自持有独立 ctx 载体，链上关联仅用于流挂载、中断传播与状态查询。
_Avoid_: 调用栈、父子上下文

**Stop / Interrupt**：
两级停止机制——Stop 仅停当前执行层剩余事件（已触发的子执行照常完成）；Interrupt 沿链向上传播（所在层及祖先层），各层在事件边界停止剩余事件、最外层正常返回。
_Avoid_: 终止、取消

**事件边界（检查点）**：
停止与中断的唯一检查点——每个事件开始执行之前；in-flight 事件必跑完。
_Avoid_: 断点

**事件流（EventStream）**：
每次执行产出的唯一 ID 记录流；子流自动挂载到触发者流（执行会话级）、条目向祖先逐级冒泡直至引擎总流。
_Avoid_: 日志、轨迹

**条目（LogEntry）**：
事件流的记录单元——kind(log/attach/update)＋timestamp(UTC)＋level(Debug/Info/Warning/Error)＋source(触发器/事件名)＋message＋keywords(扁平列表)＋data(字典)。
_Avoid_: 日志行、消息

**引擎引用**：
统一入口与 Translate 首参传入的 LogicEngine 实例；触发器不持有引擎（调用时显式传）；框架不注入 ctx 数据、不占键名。
_Avoid_: 全局引擎、单例

**顶层挂载**：
无父执行者时框架自动把执行流挂到"本次传入引擎的总流"下（多次顶层执行为总流下的兄弟流）。
_Avoid_: 手动挂载、注册

**异常隔离**：
除取消类外全部异常的捕获、记录（log/Error 条目）、继续剩余事件（事件级容错）；不涉回滚、记录失败不反噬；绑定阶段失败经「契约兜底」处理（不再原样传播）、Translate 异常不进入本路径。
_Avoid_: 吞异常、静默

**取消类穿透**：
OperationCanceledException 及其派生不被隔离、穿越途经各层直至最外层调用方（拿不到 EventStream）。
_Avoid_: 取消隔离、吞取消

**空转执行**：
已中断状态下新发起的子执行——产空流并挂载（含 attach 记录）、不执行任何事件、不绑定视图、正常返回。
_Avoid_: 跳过、忽略

**Hook**：
触发器构造期声明的"要挂载到的更新字符串"列表；被动触发器借此被总线订阅。
_Avoid_: 监听器、订阅事件

**更新**：
总线广播的单元——更新字符串（内置常量仅为便利，允许任意自定义）＋载荷字典。
_Avoid_: 通知、消息

**总线**：
按更新字符串分槽的订阅容器与广播中间层（Mount / UnmountOwner / Emit），不做逻辑编排。
_Avoid_: 事件系统、调度器

**Mount / UnmountOwner**：
被动触发器加入与退出总线订阅的两个动作；挂载按 hook 列表注册，卸载按所有者整批移除。
_Avoid_: 注册、注销

**发射（Emit）**：
总线的广播动作；按"挂载优先级升序（数值小者先）＋注册序升序"顺序 await 订阅者。
_Avoid_: 触发、分发

**更新条目**：
更新发射写入事件流的 kind=update 条目（更新类型＋载荷）。
_Avoid_: 广播记录、事件

**挂载优先级**：
同一更新内订阅者执行次序的触发器级整数（数值小者先、注册序兜底；2026-10-03 调整：方向由降序改为升序）；异于 Band（触发器内部事件次序）。
_Avoid_: 事件优先级、band

**效果（逻辑组件，S4 落地）**：
挂在卡牌上的逻辑封装（主触发器＋逻辑引用）；主触发器为主动＝主动效果，为被动＝被动效果。
_Avoid_: 技能、能力

**动态 handler（Orc.Lua）**：
由 Lua 脚本源定义、C# 侧取得并反复调用的可调用对象；环境单位＝源。
_Avoid_: 脚本回调、Lua 委托

**源单元（源）**：
一次初始化动作产生的独立 Lua 环境，也是隔离与状态延续的边界（跨源隔离、同一 handler 调用间状态延续）。
_Avoid_: 脚本实例、沙箱实例

**白名单域 / 禁用面 / 保留面 / 清单外**：
四个名字档——白名单域（宿主注册的动词命名空间，未注册读/调/写＝白名单拒绝）；禁用面（访问即失败·沙箱限制）；保留面（必须可用）；清单外（默认自然缺失 nil）。
_Avoid_: 黑名单、灰名单

**越界即显式失败**：
管控名（白名单域未注册成员、禁用面）的读/调/写一律结构化失败、不得静默；raw/元表等任何间接路径同样拦截。
_Avoid_: 宽松放行

**能力永不授予**：
不变量——无论脚本以 pcall 捕获或经间接路径绕过，未授权主体永远不会被实际调用成功。
_Avoid_: 捕获免疫、绝对安全

**统一结果对象**：
第一版公共契约——成败判别＋载荷（成功值/结构化错误）；错误分类＝编译/语法、运行时、缺失函数、编组错误（双向）、白名单拒绝、沙箱限制六类。
_Avoid_: 异常穿透、错误码

**快照式编组**：
跨边界传递为值拷贝、互不穿透；源环境内部状态延续，跨边界只传数据快照；编组错误＝跨边界值翻译失败（入/出双向）。
_Avoid_: 活引用、代理穿透

## Decisions

- S1 冻结面（后续只加不改）：IContextView.Bind/Seal 签名、两枚异常类名、四枚特性类名、Context 公共构造与最小读 API、Binder 公共创建入口。
- S1 契约速记：作者"类 + [ContextView] + 特性属性"（不声明 IContextView）；触发器泛型固定单视图、显式 Context 入参、视图单参 Task 委托、异常原样传播、无状态无名称；视图每会话新建、Seal 幂等不放松矩阵；必填缺失（含 null）抛 KeyNotFoundException、[Mutate] 可增改、[Read]+[Mutate] 同标绑定期拒绝。
- 其余 S1 决策（视图闸门、载体共享、会话/Seal、可演进边界、引用契约、交付口径等）的完整登记见 [card-engine](../card-engine/CONTEXT.md) 领域。
- **S2 触发入口与转接形态**（2026-10-03 · S2 grill 第 1 轮确认）：三形态为同一 InvokeAsync 重载族并收敛于统一入口（含引擎引用，返回 Task<EventStream>；以数据创建 ctx）；转接＝作者视图类手写静态方法（引用类参数以同一 Ref 实例入、值类参数快照入、允许直接赋值、不依赖视图实例）；框架不隐式调用 Translate、无强制契约；S1 的 RunAsync 对外调用面被取代（受控变更）；验收④口径修订为「具名路径经手写转接汇入统一入口＋字典路径零加工直入」。
- **S2 band 与注册契约**（2026-10-03 · S2 grill 第 2 轮确认）：band＝C# 枚举（成员值＝自然数、可显式指定）；二选一保护——默认枚举仅 default=0，专门枚举下注册必须显式携带成员、省略 band 或混用默认枚举成员均拒绝；装配/注册期校验（band 值须自然数且设上限、0≤内优先级<1000，越界拒绝）；注册项＝{事件名、handler、band 成员、优先级（默认 0）}；注册入口＝构造期初始集合＋构造后注册 API 并存；注册表为唯一可变面（无冻结 API、执行采用时点快照）；触发器新增可选名称（source＝触发器名/事件名，未命名退化含事件名）；事件名允许重复、仅作定位不作键；Kind 默认主动、运行期可读。
- **S2 触发器公共面与迁移**（2026-10-03 · S2 grill 第 3 轮确认）：保持单泛型 Trigger<TView>；band 方案经构造面显式声明（不得由注册隐式推断）；注册 API＝同一组双重载（无 band／带 band，band 参数可容纳任意枚举成员）＋注册期运行校验（二选一保护判定矩阵）；构造＝初始化形态（名称〔可选〕/Kind〔默认主动〕/band 方案〔默认缺省〕/初始事件集合〔可选〕，承载形状实现择定）；S1 旧构造与 RunAsync 不保留兼容层，既有测试改写迁移（保持验收语义覆盖），S1 基线以迁移后全套测试全绿为准。
- **S2 执行链与停止语义**（2026-10-03 · S2 grill 第 4 轮确认）：嵌套链各执行 ctx 独立（不共享载体、数据严格显式传递、无继承语义）；嵌套关系由统一入口自动感知（执行栈/AsyncLocal 或等效机制，栈空＝顶层挂总流）；Stop＝仅本级；Interrupt＝所在层及祖先层在事件边界停止、最外层正常返回 EventStream、已中断后不再启动新执行单元的事件序列；检查点＝事件边界（每个事件执行前，in-flight 必跑完）。
- **S2 事件流契约**（2026-10-03 · S2 grill 第 5 轮确认）：子流挂载＝执行会话级、持久保留、不封口；冒泡＝全量 kind、同一条目、逐级至根（含总流）；attach 写父流（data 必备 parentId/childId）、子流侧关系由父流引用读面承载；level 固定四档、timestamp＝UTC、keywords＝扁平字符串列表（允许 key:value）；公共读面＝唯一 ID＋父流引用＋条目/子流可枚举；log 与 update 公共写面就绪（update 实际接线留 S3）；框架自动写＝attach、异常隔离记录、Stop/Interrupt 记录（均 kind=log，Interrupt 取级高于 Stop）；异常路径已写入条目保留。
- **S2 引擎引用与 LogicEngine 壳**（2026-10-03 · S2 grill 第 6 轮确认）：引擎引用＝LogicEngine 实例，经调用显式传入（触发器不持有、无全局单例、框架不自动注入 ctx 数据）；handler 内嵌套触发用闭包捕获或经作者数据（皆合法）；顶层挂载目标＝本次传入引擎的总流（多次顶层执行为兄弟流）；公共面严格止于总流读＋顶层挂载（不预埋 S3 总线结构）；链标识（ChainId/Depth）判定不落地——链的可视表达由事件流树结构承担。
- **S2 异常隔离与取消语义**（2026-10-03 · S2 grill 第 7 轮确认）：隔离范围＝除取消类（is OperationCanceledException，含派生）外全部异常；记录义务（kind=log、level=Error、source、message、keywords 含异常类型名，data 自由）至少一条写当前执行流；当前层剩余事件继续、父层不受影响、无回滚、记录失败不反噬；绑定阶段失败与 Translate 异常不进入隔离路径、原样传播（S1 用例语义保持）；取消类穿透途经各层直至最外层；框架不主动检查 ct（透传义务成立），验收⑦＝主动 throw OCE 即可。
- **S2 方法级收口**（2026-10-03 · S2 grill 第 8 轮确认）：顶层流父引用＝总流对象（总流为根、无父；读面＝流对象引用＋ID 属性）；空转执行＝产空流＋按统一规则挂载（含 attach）＋不执行事件＋不绑定视图；"不启动新执行单元"分层＝后续事件不被触达／in-flight 内已发出的调用被调用但空转；一次执行＝一个视图实例（与 ctx 同构、全部事件共用）、结束 Seal 一次（异常路径不跳过）；工程红线全部延续（InternalsVisibleTo 禁令、无独立文档产出、不删文件、不 git 提交、无 Source Generator）；S1 测试允许同文件重组重写（文件保留、验收语义覆盖保持）。
- **S2 开放性定夺与终极复查**（2026-10-03 · S2 grill 第 9 轮确认）：Trigger<TView> 开放继承（取消 sealed；属受控变更；继承者契约＝不绕过公共执行/注册面、不引入新可变状态面、泛型约束不破坏）；公共执行面唯一＝统一入口（RunAsync 不保留对外形态）；所有框架写入条目 source 统一按"触发器名/事件名"（未命名退化含事件名）；验收证据沿用 S1 口径（映射可完整指认即达标）；实现择定项＝最小化＋汇报记录、已定口径冲突＝暂停并反馈。


- **Orc.Lua 动态 handler 状态模型**（2026-10-03 · Orc.Lua grill 第 1 轮确认）：环境单位＝脚本源（每源初始化一次得独立 Lua 环境）；同源多个 handler 共享源环境与状态（设计特性）；跨源隔离（脚本侧一切——全局/模块状态、脚本定义物——互不可见互不干扰）；同一 handler 连续调用状态延续（有状态可复用，复用价值＝免重复解析＋状态延续）；按名获取不重执行源（同名重复获取＝等价引用；独立实例以两份源满足，显式多实例 API 后置）；白名单可见性＝宿主级共享（按源差异化授权后置）；错误隔离性＝任一 handler 失败不影响其他源与其他 handler 环境；资源限制（执行时长/内存）后置。


- **S3 触发器侧契约**（2026-10-03 · S3 grill 第 1~2 轮确认）：hook 仅构造期声明（Active+hooks 非空＝构造期拒绝；Passive+空 hooks＝可存在不可挂载）；Owner 为构造期可选 object（null 合法、引用相等匹配）；Mount 拒绝四类＝null／Kind=Active／hooks 空／已挂载（"已挂载"为触发器实例级、跨总线亦拒绝、卸载后复位可重挂）；挂载优先级＝构造期声明、默认 0、任意 int 合法；hooks/priority/owner 均不公开只读属性；本阶段仅 UnmountOwner 一种卸载途径（null 拒绝、未命中幂等且不写留痕）。
- **S3 总线归属与引擎壳**（2026-10-03 · S3 grill 第 2 轮确认）：总线与引擎一对一绑定（engine.Bus 只读、engine.Emit 纯转发、总线不可独立构造）；多引擎互不相通；订阅读面单向（更新→订阅者展示名有序快照、未知返空）；LogicEngine 保持 sealed/多实例/RootStream，加性面仅 Bus 属性＋Emit 转发。

## S4 术语补充（2026-10-03 grill）

**效果（Effect）**：
挂在卡牌上的逻辑组件；恰含一个主触发器与作者覆写钩子（OnMount 注入／OnUnmount 清理）。
_Avoid_: 技能、插件

**主触发器**：
效果在总线上的运行时代表（主动或被动；每个效果恰一个）；装载/卸载的对象。
_Avoid_: 效果触发器

**装载／卸载**：
效果随放置进入运行态（挂载主触发器＋OnMount）与随移除／销毁退出运行态（OnUnmount＋总线卸载）的动作对。
_Avoid_: 初始化、注销

**注入**：
效果把 handler 经流程触发器的注册面写入具名 band 的动作；清理时必须实际撤销（注册表移除），不接受执行期短路。
_Avoid_: 挂接

**流程（攻击／伤害结算／指令流程）**：
分离的通用编排单元——攻击（发起方：反制检查→调用伤害结算→收尾）、伤害结算（承受方：结算前阶段→伤害生效）、指令流程（主动效果→调用伤害结算）。
_Avoid_: 战斗系统

**具名 band 扩展位**：
流程内供效果注入的具名区段（复用 band 机制）。
_Avoid_: 槽位、钩子

**驱动信号**：
card.placed／effect.removed／card.destroyed 三更新的角色定位——先广播、订阅方响应完成装载/清理（区别于"完成通知"模型）。
_Avoid_: 事件通知

**本地条目（事件流 JSON 语境）**：
事件流 JSON 导出中节点呈现的条目＝该流自身写入的条目；后代冒泡条目不出现在祖先节点，同一条目在树中恰出现一次。
_Avoid_: 全量条目、冒泡条目

**指令流程（OrderFlow）**：
引擎级共享的施放载体（与攻击／伤害结算流程同构；原「施放流程（SpellFlow）」更名），承载供反制类效果经既有接线注入的具名检查位；指令施放经规范路径经过检查位。
_Avoid_: 施放流程（旧名）、SpellFlow、法术实例钩子、施放直调

**实体标识（EntityId）**：
实体级加性标识，快照输出的稳定关联字段（重名 Name 不承担标识语义）。
_Avoid_: 显示名、重名键

**引擎桥（IEngineBridge）**：
宿主在编译期实现的单向接口（更新通知通道）；引擎持可空引用并在更新广播时调用。
_Avoid_: 插件、事件系统

**引擎订阅（Subscribe）**：
外部在运行期向引擎注册更新回调的注册面；多订阅、可取消、回调异常不破坏广播主流程。
_Avoid_: 触发器挂载、总线订阅

**卡牌登记**：
引擎级卡牌列表（创建即注册、销毁后移除），全量快照的数据来源。
_Avoid_: 棋盘、在场管理

## Decisions（S4，2026-10-03 grill）

- 装载链（轮 1）：放置＝发射 card.placed 驱动装载（不引入游戏流程层放置 API）；重复放置/移除/销毁幂等；销毁清理范围＝该卡牌全部效果。
- 效果与主触发器（轮 1）：一效果一主触发器；装载＝挂载→OnMount，卸载＝OnUnmount→卸载；作者写 OnMount/OnUnmount，框架管更新接线、顺序与幂等。
- 清理语义（轮 2）：清理＝实际撤销注入＋总线卸载＋作者专属清理；多效果隔离＝专项验收；RemoveEffect 从 Effects 列表移除、可重新装载；已放置卡牌 AddEffect 即时装载（不得静默死效果）。
- 流程分离验收（轮 2）：伤害结算先于回血＝强制项；分离观测＝独立触发或事件流父子结构；施放覆盖≥1 用例；反制/收尾为具名 band 扩展位（默认处理器非必须）。
- 容器语义（轮 3/5）：数据组件键＝类型、每卡每类型一份；重复 Add 拒绝（数据组件同类型／效果同实例）、缺失抛明确异常；数据类任意类、引用共享；Effects 为只读枚举面。
- 移除/销毁入口（轮 3）：规范销毁＝一步式辅助（杀＋发 card.destroyed；Destroy() 自身语义不变）；移除双路径（RemoveEffect／effect.removed）收敛于同一清理模板；未装载移除＝仅容器面；全部幂等。
- 主动效果（轮 4）：不执行 OnMount/OnUnmount、纯列表进出（钩子＝装载语境专属）。
- 撤销责任（轮 4）：注入经装载语境登记、卸载时框架自动撤销；作者 OnUnmount 只写专属清理。
- 重装与重入（轮 4）：移除后可重新 Add、OnMount 再次执行；钩子可多次成对（幂等边界由框架保证）。
- 验收锚点（轮 4/5）：多卡牌/多效果隔离分别专项；钩子断言＝次数、次序、失败隔离、上下文可获取；验收基线已冻结（六组锚点清单，详见需求文档），行为断言必测、注册面机制核验可选。

## E-D1 disposing 触发器（2026-10-18 grill）

**disposing 触发器**：
与效果业务主触发器并列、**默认必选**的独立 `Trigger`；`hooks`＝兜底时机（与主触发器同构的更新名字符串），事件链＝效果额外副作用清理；提前调用与兜底调用进入同一销毁入口。
_Avoid_: 销毁钩子、清理触发器

**销毁状态（DisposalState）**：
`NotMounted`／`Mounted`／`Disposing`／`Disposed`；复装复位。
_Avoid_: 死亡标志

**保留 band**：
Trigger 内部保留槽（非枚举成员）：构造期即存在、排序恒在全部普通事件之后、普通注册不可写入；只接受 `RegisterDisposal`。
_Avoid_: 销毁区段

**决策摘要**：
- 调用即完整销毁：执行 disposing 事件链 → 最终 teardown → 容器移除 → 恰发一次 `effect.removed`；进入即停用（卸该效果全部总线挂载＋撤销注入）；重复/重入空转；异常仍完成终态。
- 兜底 hooks：默认强制 `card.destroyed` 且不可移除；`effect.removed` 被拒绝（自指）；`match.ended` 后续待办。
- 双层注销：核心句柄撤销（注入登记/托管清理）由框架最终层保证；手写 disposing 只处理额外副作用。
- 生命周期触发器退场（disposing 取代）；C# 被动效果 `MainTrigger=null`（纯注入型）；动态效果业务主触发器保留并与 disposing 并列；主动效果 disposing 照常挂总线。
- `OneShot`：仅在有可挂载业务主触发器时成立；纯注入型/无 hooks 明确失败；主动效果＝施放完成即销毁。
- 预制体 schema 3：`root.disposingTrigger`/`root.oneShot`；`EventPrefab.band ∈ {default, disposing}`；接受 2 读入并归一化为 3，写出恒 3。
