# 人类 CLI 客户端 · 使用说明

用终端和 AI 打一局。你坐 seat 0（先手），AI 坐 seat 1。

## 启动

- **双击 `tools\orc_play.bat`** —— 等同 `play`，全屏界面。首次运行会在 `tools\orc\.venv` 建隔离环境并装 `prompt_toolkit`（约 30 秒，之后秒开）。
- 命令行同一入口：`tools\orc_play.bat play`、`tools\orc_play.bat --help`。
- 行式界面（零依赖，任何 Python 3.9+ 都能跑；管道/重定向也可用）：
  ```bash
  python tools/orc_play.py play --plain
  ```
- 脚本内部会把工作目录切到仓库根并 `chcp 65001`，所以在任何目录双击都能正确找到卡包与中文输出。

**前置：管理器要在跑。** 客户端默认连 `127.0.0.1:51999`：

- 已经开着管理器窗口 → 直接启动客户端。
- 没开 → 加 `--launch-manager`（由客户端拉起，退出后仍常驻），或先双击 `start-manager.bat`。
- **重要**：如果你机器上的 51999 是很久以前启动的进程，它的 `deckRules` 参数还不生效（仍按严格卡组校验），开局会报 `deck-invalid`。关掉旧窗口重开一次 `start-manager.bat` 即可；或临时用另一个端口：
  ```bat
  tools\orc_play.bat play --manager 127.0.0.1:52001 --launch-manager
  ```

## 一局怎么走

开局是**换牌阶段**，最短路径就一条命令：

```
keep          # 不换牌，直接开始（也可以 mulligan 选择要换掉的牌）
```

进入对局后，画面自上而下是：对手区 / 我方区 / 手牌 / 日志 / 提示条。

```
play 3        # 打出第 3 张手牌（单位会问你插在哪；指令可能直接结算；反制直接生效）
play 3 2      # 一步到位：第 3 张牌，插入位选 2
attack 2      # 用我方 2 号单位发起攻击，然后选目标
move 2        # 2 号单位移动，然后选目的地
leave 2       # 2 号单位离开战场
end           # 结束回合
concede       # 认输（会二次确认）
hand / units  # 看手牌 / 看我方单位（纯本地，不发请求）
log 20        # 回看最近 20 条战斗日志
help          # 全部指令（中英两套写法）
quit          # 退出（对局中会二次确认）
```

- 所有指令都有中文别名：`出牌`、`攻击`、`移动`、`离开`、`结束回合`、`认输`、`保留`、`换牌`、`手牌`、`单位`、`日志`、`帮助`、`退出`。
- 进入选择模式（选插入位 / 选目标 / 选换牌）后：输入序号（可多选，逗号或空格分隔）→ `ok` 提交，`x` 取消。
- 全屏界面里 Tab 补全；行式界面在参数缺失时会直接把候选打出来。
- 序号永远指"当前屏幕上看到的位置"；战场变了编号会重排，执行前会回显目标名。

## 退出与回座

- `quit` 默认**销毁实例**（干净收场）。
- `--keep-instance` 退出时保留实例：下次 `play` 会凭座位令牌自动回到原座位，不用重新开局。
- 断线/关终端后重跑 `play`，同样会先尝试回座。

## 观战

```bat
tools\orc_play.bat watch --instance cli-xxxxxxxx
```

不绑座的全知视角：A/B 双方手牌、共享前线、只读（`hand [0|1]` / `units [0|1]` / `log` / `help` / `quit`）。不写会话记录，不影响对局。

## 常用参数

| 参数 | 作用 |
|---|---|
| `--manager host:port` | 管理器地址（默认 127.0.0.1:51999） |
| `--launch-manager` | 管理器不在时由本次会话拉起（常驻，不会随退出被关） |
| `--pack <目录>` | 换卡包（默认 `samples/card-pack-ai`） |
| `--deck <json>` | 用自定义卡组（JSON 字符串数组，卡 id 形如 `pack/ai.sample/ai.sample.infantry`） |
| `--plain` / `--tui` | 强制行式 / 强制全屏 |
| `--keep-instance` | 退出时保留实例（供回座） |
| `--new` | 忽略记录，新开一局（不动旧实例） |
| `--verbose` | 日志附 `(seq=N)` 追溯，并显示装配期事件 |

## 排错

- **`管理器未运行`**：按提示启动；或加 `--launch-manager`。
- **`卡组为 39 张，要求 39 张` / `deck-invalid`**：管理器是旧进程，重启它（见上）。
- **`未检测到 prompt_toolkit，已使用 --plain`**：没建 venv，跑一次 `tools\orc_play.bat` 即会安装；无网时用 `--plain` 也能打完一整局。
- **`实例 cli-xxx 已销毁`**：正常退出；想保留就加 `--keep-instance`。
- **双击后窗口一闪而过**：现在失败时窗口会停住并显示 `[orc] exited with code N`；若仍然闪退，说明连 bat 都没跑起来，请在命令行执行 `tools\orc_play.bat play` 看具体输出。
