# Requirements — 太空战争（强磁护盾 / 磁反应装甲 / 海绵装甲 / 游击）

为 Orc 引擎的游戏层新增四个拓展词条（强磁护盾、磁反应装甲、海绵装甲、游击），以独立卡包形式分发。

## Scope
- Includes: 四个词条的外部行为（触发时机、作用对象、数值、失去条件、相互耦合）＋独立卡包的组织约定与示例卡/使用文档。
- Excludes: 承载路径（C# 组件 / csx 效果 / 判定器包装器 / 新增信号）——见实现文档；卡面美术、本地化、平衡数值调优；包名/显示名（最后补齐）。

## Constraints
- 卡包词条不得与引擎内建/他包词条重名（`CardPackKeywordLoader` 拒绝）。
- 包内 `keywords.json` 的每个词条必须有至少一项效果绑定。
- 行为需可被自动化测试验证（对局级单测），并保持 P1（改变才传播）/ P2（同步顺序语义）。
- 四词条同包，互不依赖其它卡包。

## Requirement Items

### R1: 独立卡包「太空战争」
- Status: Confirmed
- 身份：目录 `samples/card-pack-space-war`、包 `id=orc.space-war`、显示名「太空战争」、独立 guid、卡前缀 `pack/orc.space-war/`。
- Scenario/Trigger: 装载该卡包时。
- Behavior: 四个词条与行为制品随包分发；包可热加载、可被预检（Errors=Warnings=0）；不与内建词条冲突；不动既有 `orc.bulwark` 包。
- Acceptance:
  - [ ] 包清单合法（kind=cardpack、guid、version），目录含 `keywords.json` 与行为制品。
  - [ ] 装包后四个词条注册可查，且对新建对局生效。
  - [ ] 预检 Errors=Warnings=0；示例卡可加载。
  - [ ] 4 张示例卡（强磁护盾步兵 / 磁反应装甲坦克 / 海绵装甲步兵〔同带强磁护盾〕/ 游击步兵）。
  - [ ] 包内 `README.md` ＋ 面向玩家的 `使用指南.md`。
- Terminology: 卡包、词条、词条效果库、资产名

### R2: 强磁护盾
- Status: Confirmed
- Scenario/Trigger: 具有「强磁护盾」的单位受到任意来源伤害时；该单位成功完成玩家指挥的攻击后。
- Behavior:
  - 对战伤害（combat）/ 效果伤害（effect）/ 战斗伤害（battle）**均 -1**，下限 0；1 点伤害减到 0 时**不构成「受到伤害」**（引擎在实扣为 0 时不发射 `card.damaged`）。
  - 同一单位重复获得**不叠加**（恒为 -1）。
  - 失去：仅「玩家指挥的攻击**成功完成**」后失去，失去发生在**本次攻击伤害结算之后**（本次仍享受 -1）；攻击被取消 / 复验拒绝 / 未成功不失去。
  - 「成功完成」判定＝攻击产生了伤害结算即算；对方单位已死导致无伤害结算，也算失去。
- Acceptance:
  - [ ] 三种来源的伤害各 -1，下限 0。
  - [ ] 1 点伤害被减到 0 时，不发射 `card.damaged`、不计「受到伤害」。
  - [ ] 重复获得不叠加（仍为 -1）。
  - [ ] 指挥攻击成功后失去词条，且本次攻击仍享受 -1。
  - [ ] 攻击取消 / 复验失败 / 未成功时不失去。
  - [ ] 攻击目标已死（无伤害结算）仍失去。
- Terminology: 词条、伤害、攻击

### R3: 磁反应装甲
- Status: Confirmed（子项 Q4a/Q4b 取默认）
- Scenario/Trigger: 具有「磁反应装甲x」的单位被敌方指向后。
- Behavior:
  - 带参词条：数据体写法 `Keyword:磁反应装甲:<n>`；合法范围 1–2（写 >2 钳到 2），未写值默认 1。
  - 「具有免疫」＝内建免疫语义：受到的伤害归零；**不**拦索敌、**不**防抑制。
  - 免疫与「强磁护盾」：先归零，故两者不叠加（-1 无意义）。
  - 每次被敌方指向 x-1；x=1 时仍免疫；x 归 0 时移除词条。
  - 同一单位不叠加（重复授予取较大值）。
  - 「被敌方指向」＝① 敌方卡牌效果**最终选定**本单位为目标，或 ② 敌方**指挥攻击**指向本单位；承载为通用「指向」中间动作缝。候选名单枚举、未选定、取消选择均不算。
  - 每次指向 x-1（一次动作内被指向多次则各扣 1）；效果发起的攻击不算「指挥攻击」。
- Acceptance:
  - [ ] 声明 `X=2` 时被指向一次变 `X=1`，仍免疫；再被指向一次词条移除。
  - [ ] 声明值 >2 被钳到 2；未写值默认 1。
  - [ ] 持该词条时受到的伤害归零，且不影响索敌与抑制。
  - [ ] 与「强磁护盾」并存时伤害为 0（不叠加 -1）。
  - [ ] 同一单位重复获得只保留较大 x。
  - [ ] 敌方效果选定本单位 / 敌方指挥攻击指向本单位 → 各扣 1 层；仅被列为候选不扣。
  - [ ] 一次动作指向本单位 N 次 → 扣 N 层（不足则移除）。
- Terminology: 词条、免疫、目标

### R4: 海绵装甲
- Status: Confirmed
- Scenario/Trigger: 具有「海绵装甲」的单位受到伤害，且结算时该单位同时持有「强磁护盾」。
- Behavior:
  - 本次伤害的**最终值封顶为 1**（对战 / 效果 / 战斗三种伤害均适用）。
  - 封顶发生在所有减伤/加伤之后（伤害修正链的最后一步）。
  - 没有「强磁护盾」时「海绵装甲」完全无效。
  - 最终为 0 → 不构成「受到伤害」；为 1 → 正常受伤；与「磁反应装甲」免疫并存时保持 0。
- Acceptance:
  - [ ] 持强磁护盾 + 海绵装甲：5 点伤害 → 1。
  - [ ] 仅持海绵装甲（无强磁护盾）：5 点伤害 → 5（不封顶）。
  - [ ] 强磁护盾 + 海绵装甲：1 点伤害 → 0，不发射 `card.damaged`。
  - [ ] 与磁反应装甲并存：伤害 0（免疫优先，封顶不改变 0）。
- Terminology: 词条、伤害

### R5: 游击
- Status: Confirmed
- Scenario/Trigger: 具有「游击」的单位执行指挥移动时。
- Behavior:
  - 等同程序规则 `move.retreat`：位于**前线**时可指挥移动到**支援线空槽**。
  - 支援线 → 前线的既有能力不受影响；不新增支援线内换位。
  - 照常消耗行动额度与行动费；支援线无空槽时不可移动。
  - 与「固守」同持时固守优先（不可指挥移动）；效果位移不受影响。
- Acceptance:
  - [ ] 前线持「游击」单位可指挥移动到支援线空槽。
  - [ ] 支援线无空槽时不可移动。
  - [ ] 移动照常扣行动额度与行动费。
  - [ ] 支援线 → 前线仍可移动。
  - [ ] 同时持「固守」时不可指挥移动；效果位移仍可。
- Terminology: 词条、指挥移动、支援线
