# 「太空战争」卡包使用指南

这份指南带你把这个卡包放进游戏数据目录，并在对局里用上「强磁护盾」「磁反应装甲」「海绵装甲」「游击」四个词条。

---

## 一、这个卡包里有什么

卡包里有四个词条和四张示例卡：

| 词条 | 在牌桌上的效果 |
|---|---|
| **强磁护盾** | 单位受到的伤害减 1（无论伤害来自对战、卡牌效果还是战斗）。单位主动攻击（你指挥的攻击）成功后立刻失去「强磁护盾」，但**这次攻击仍然减伤**。 |
| **磁反应装甲** | 单位具有免疫（受到的伤害为 0）。被敌方指向（敌方卡牌效果选中它，或敌方攻击它）后层数 -1；层数降到 0 时失去。最多 2 层。 |
| **海绵装甲** | 只有同时具有「强磁护盾」时才有用：受到的伤害最多为 1。没有「强磁护盾」时这个词条不产生效果。 |
| **游击** | 单位在前线时可以指挥移动回支援阵线（退到后排）。 |

四张示例卡：

- **磁盾步兵** —— 带「强磁护盾」
- **磁反应坦克** —— 带「磁反应装甲2」
- **海绵装甲步兵** —— 同时带「强磁护盾」和「海绵装甲」（演示联动）
- **游击步兵** —— 带「游击」

---

## 二、卡包放在哪里

游戏从数据目录 `kards/packs` 读取卡包。源码编辑器里应放在：

```
<编辑器工程>\proto\data\kards\packs\card-pack-space-war\
```

完整结构：

```
card-pack-space-war\
├── manifest.json
├── keywords.json
├── effects\
└── cards\
```

放好后的检查：

- 打开 `card-pack-space-war` 文件夹，**第一眼就应该能看到 `manifest.json`**（如果看到的是又一层 `card-pack-space-war`，说明多套了一层）。
- `manifest.json` 里的 `id`（`orc.space-war`）是卡包身份，不要随便改。
- `manifest.json` 里的 `name` 决定卡包在图鉴里的显示名（当前是「太空战争」）。

---

## 三、让编辑器读取卡包

1. 在编辑器里停止当前运行。
2. 重新运行。
3. 新建一局对局。
4. 打开卡牌图鉴或组卡页面，搜索这四张示例卡。
5. 把卡加入卡组，开始对局。

说明：

- 卡包只在启动时发现；**已经打开的对局不会自动出现新卡**，请新建对局。
- 编辑器控制台如果出现「卡包/插件装载隔离：…」，说明该卡包装载失败，按提示里的包名与原因检查文件。

---

## 四、对局里怎么用

### 强磁护盾

1. 单位在场时，每次受到的伤害都少 1（1 点伤害会被完全挡掉）。
2. 你指挥它攻击一次后，「强磁护盾」消失；这次攻击本身仍然享受减伤。
3. 被动挨打不会失去它；攻击被取消/没有真正打出去也不会失去。

### 磁反应装甲

1. 单位一直免疫伤害。
2. 每当敌方把它选为目标（卡牌效果或攻击），层数 -1：`磁反应装甲2` → `磁反应装甲1` → 失去。
3. 1 层时仍然免疫；层数降到 0 才失去。
4. 友方指向它、或者只是被列为可选目标，都不会扣层。

### 海绵装甲

1. 单独存在时没有效果。
2. 与「强磁护盾」同时在同一个单位上时：受到的伤害先 -1，再封顶为 1（例如 5 点伤害 → 1；1 点伤害 → 0，完全挡掉）。
3. 强磁护盾在攻击后失去后，海绵装甲也随之不再生效。

### 游击

1. 把「游击步兵」放到前线。
2. 到你的回合，把它拖回支援阵线的空位即可（照常消耗行动机会与行动费）。
3. 支援阵线没有空位时无法移动。
4. 如果单位同时有「固守」，固守优先——仍然不能指挥移动。

---

## 五、看不到卡或词条不生效时

1. **图鉴里没有四张示例卡**：确认卡包在 `proto\data\kards\packs\card-pack-space-war\`、`manifest.json` 只隔一层、编辑器已停止后重新运行、并新建对局。
2. **卡出现了但词条没反应**：确认对局是卡包装载之后新建的；确认没有另一个卡包使用同名词条（同名词条会被拒绝加载）。
3. **磁反应装甲不显示层数**：卡数据里写的是 `"Keyword:磁反应装甲:2"`（不是 `"磁反应装甲2"`），检查卡文件。
4. **游击不能后退**：确认单位在**前线**、支援阵线有**空位**、且单位本回合还有移动机会。

## 六、自己改一改

### 改卡名和数值

用记事本打开 `cards` 文件夹里的卡文件：

- `"name"` 后面引号里的字是卡名；
- `"attack"` 是攻击力、`"defense"` 是防御力、`"operationCost"` 是行动费用；
- 只改引号里的文字或数字，不要删除大括号、逗号。

改完保存，重新运行编辑器，新建对局。

### 给别的卡加上这四个词条

在卡文件的 `keywords` 方括号里加词条名：

```
"keywords": ["强磁护盾", "海绵装甲"]
```

带参词条用完整写法：

```
"keywords": ["Keyword:磁反应装甲:2"]
```

### 做一张新卡

1. 复制一张现有卡文件，改文件名；
2. 把文件里的 `"id"` 改成新名字（不能和现有卡重复）；
3. 改 `"name"`、数值和 `keywords`；
4. 保存、重新运行、新建对局。

同时要给新卡补一个同名的 `.meta.json`（sidecar），否则资产不会注册。
