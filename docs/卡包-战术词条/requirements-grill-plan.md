# Requirements Grill Plan — 战术词条卡包（机动 / 固守 / 抢修）

> 聚焦三个拓展词条的外部行为与卡包边界；承载路径问题暂记实现阶段。

## Unresolved Questions

### Q1-Q6 Completed
- Q1：机动＝额度模型（D）。Q2：首次行动即移除（a）。Q3：压制不影响词条存留。
- Q4：行动费照扣（a）。Q5：坦克同样适用（B）。Q6：机动+奋战=3 打（D）。

### Q7: 行动额度的基础语义 Completed（A）
- 非坦克每次行动两个额度各减一（不清零）；坦克只减本次动作对应额度。
- 基础额度各 1、每己方回合恢复。

### Q7b: 奋战单位移动后可攻击 Completed（接受变更）
- 结论：接受"减一"带来的行为变更。

### Q7c: 机动的减免落点 Completed
- 结论：机动＝**本回合攻击额度 +1**（移动/攻击均生效，含坦克移动）；而非"本次动作对应额度减免"。
- 依据：用户三场景（奋战先移动再打 2、先攻打 3；坦克动一次打两次）只在该表述下自洽。

### Q8: 奋战额度重置 Completed（a）
- 每己方回合重置为基础 +1（攻击额度 2），不累积。

### Q9: 固守的「抑制」所指 Completed（A）
- 结论：只免疫「抑制」（`InhibitRules`）；被「压制」（`Suppressed`）仍按压制结算。
- 实现指示（用户）：在抑制的处理触发器上加判定器，判定单位是否可抑制（记 P4）。

### Q10: 固守的「撤退」/效果位移 Completed（最终 a，推翻前答 b）
- 结论：固守**只拦指挥移动**（含撤退）；**可被效果强制位移**。
- 注：上一轮答 b（连效果位移一起拦），本轮修正为"被效果影响可以移动"，以本轮为准。

### Q11: 抢修的修复量 Completed（A）
- 结论：回满（损伤清零，受有效防御上限约束）。

### Q12: 抢修的时间窗口 Completed（a/a）
- 窗口：上次己方回合开始 → 本次己方回合开始之间，未移动/未攻击。
- 部署当回合：算"没有移动或攻击"，下个己方回合开始即可修复。

### Q13: 抢修的失去条件 Completed（A）
- 结论：位于前线即无「抢修」——移动到前线、效果位移到前线、**部署在前线**均立即失去；撤离前线不恢复。

### Q13b: 抢修的移动/攻击口径 Completed（a/b）
- 移动：任何位置变化（指挥移动/效果位移/撤退）。
- 攻击：仅玩家指挥的攻击（`unit.acted` 路径）；效果发起的攻击不计入。
