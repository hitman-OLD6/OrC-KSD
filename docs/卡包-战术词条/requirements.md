# Requirements — 战术词条卡包（机动 / 固守 / 抢修）

为 Orc 引擎的游戏层新增三个拓展词条（机动、固守、抢修），以独立卡包形式分发。

## Scope
- Includes: 三个词条的外部行为（触发时机、作用对象、效果、消耗/失去规则）＋独立卡包的组织约定（包名、词条声明、行为制品归属）。
- Excludes: 具体承载路径（C# 组件 / 程序化词条 / csx 效果 / 引擎读取口扩展）——见实现文档；卡面美术、文本本地化、平衡性数值调优。

## Constraints
- 卡包词条不得与引擎内建/他包词条重名（`CardPackKeywordLoader` 拒绝）。
- 卡包内 `keywords.json` 的每个词条必须有至少一项效果绑定（无 bindings 不允许发布）。
- 行为需可被自动化测试验证（对局级 BDD/单测），并保持 P1（改变才传播）/P2（同步顺序语义）。
- 额度模型会改变现有"奋战单位移动后不可攻击"的行为（见 R1 备注），已显式接受。

## Requirement Items

### R1: 机动
- Status: Confirmed
- Scenario/Trigger: 具有「机动」的单位在本回合首次**成功**执行行动（移动或攻击）时。
- Behavior: 本回合**攻击额度 +1**，随后**立即移除「机动」**；行动费照常扣除。未行动则词条跨回合保留；被压制只导致无法行动，不影响词条存留。
- 额度模型（用户裁定 D）：
  - 单位持有「移动额度」「攻击额度」的组件；基础额度各 1，每己方回合恢复。
  - 非坦克：每次行动**两个额度各减一**（不是清零）。
  - 坦克：只减本次动作对应的额度。
  - 机动：本回合攻击额度 +1（然后移除自己）。
  - 奋战：每己方回合**重置**为基础 +1（攻击额度 2）。
- 用户裁定行为（推导锚点）：
  - 奋战：攻击一次后无法移动，只能再打。
  - 机动 + 奋战：先移动 → 再打两次；先攻击 → 无法移动，只能打三次。
  - 坦克 + 机动：动一次 + 打两次。
- 备注（行为变更）："减一"使奋战单位移动后攻击额度仍有剩余（现状为清零、移动后不可攻击）——已确认接受。
- Acceptance:
  - [ ] 首次成功行动后，攻击额度 +1 生效（移动/攻击均适用，含坦克移动）。
  - [ ] 首次成功行动后，「机动」被移除（恰一次）。
  - [ ] 行动被取消、复验拒绝或未执行时：不消耗词条、额度不变。
  - [ ] 未行动（含被压制、非己方回合）时词条保留，可跨回合继续持有。
  - [ ] 首次（免费）行动照常扣行动费。
  - [ ] 坦克 + 机动：动一次 + 打两次。
  - [ ] 非坦克 + 机动 + 奋战：先移动 → 1 动 + 2 打；先攻击 → 3 打、不能移动。
  - [ ] 机动 + 奋战 ⇒ 最多攻击 3 次。
- Terminology: 行动额度（新术语，定稿后并入 CONTEXT）、词条、行动位

### R2: 固守
- Status: Confirmed
- Scenario/Trigger: 具有「固守」的单位在场期间。
- Behavior: 该单位**无法被指挥移动**（含撤退）；**可被效果强制位移**（如「撤退」/被控移动）。无法被抑制（`InhibitRules`）。
- 实现指示（用户）：在抑制的处理触发器上加判定器，判定单位是否可抑制。
- 备注（用户）：KARDS 单位不能主动撤退，故「无法撤退」主要对具备撤退能力的规则/效果路径生效。
- Acceptance:
  - [ ] 该单位不能执行指挥移动（含撤退）。
  - [ ] 该单位可以被效果强制位移（`MoveUnitAsync`，含「撤退」效果）。
  - [ ] 「抑制」施加到该单位时被判定拒绝且零副作用。
  - [ ] 其它单位可被重复抑制（「被抑制」仅为视觉标记，不作拒绝依据）。
  - [ ] 拦截不影响攻击、被攻击与其它行动。
  - [ ] 被「压制」（`Suppressed`）仍按压制结算（固守不免疫压制）。
- Terminology: 移动、撤退、抑制、压制、判定器

### R3: 抢修
- Status: Confirmed
- Scenario/Trigger: 友方回合开始，且本单位上次己方回合开始至本次己方回合开始之间没有移动或攻击。
- Behavior: **回满**本单位（损伤清零，受有效防御上限约束）。**位于前线即无「抢修」**：移动到前线、被效果位移到前线、部署在前线均立即失去（失去后不再修复；撤离前线不恢复）。刚部署的当回合同样算"没有移动或攻击"，下个己方回合开始即可修复。
- 口径（用户）：移动＝任何位置变化（指挥移动/效果位移/撤退）；攻击＝仅玩家指挥的攻击（效果发起的攻击不计入）。
- Acceptance:
  - [ ] 条件满足时，友方回合开始后本单位损伤清零（满血时幂等、零发射）。
  - [ ] 上次己方回合开始以来移动过或攻击过则不修复。
  - [ ] 移动到前线/被效果位移到前线/部署在前线时「抢修」被移除（恰一次）。
  - [ ] 撤离前线后不恢复「抢修」。
  - [ ] 未在场/已死亡的单位不修复。
  - [ ] 部署当回合不排除触发（下个己方回合开始即可修复）。
  - [ ] 效果发起的攻击不阻止修复。
- Terminology: 修复、回合开始、前线、支援线

### R4: 独立卡包
- Status: Confirmed
- Scenario/Trigger: 装载该卡包时。
- Behavior: 三个词条与行为制品随包分发；包可热加载、可被预检（Errors=Warnings=0）；不与内建词条冲突。
- Acceptance:
  - [ ] 包清单合法（kind=cardpack、guid、version），目录含 `keywords.json` 与行为制品。
  - [ ] 装包后三个词条注册可查，且对新建对局生效。
  - [ ] 卸载不注销词条（沿既有 D5 语义）、不破坏既有词条注册面。
- Terminology: 卡包、词条效果库、资产名
