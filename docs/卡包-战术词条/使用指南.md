# 「铜墙铁壁系列」卡包使用指南

这份指南带你把这个卡包放进游戏数据目录，并在对局里用上「机动」「固守」「抢修」三个词条。

---

## 一、这个卡包里有什么

卡包里有三个词条和三张示例卡：

| 词条 | 在牌桌上的效果 |
|---|---|
| **机动** | 单位本回合第一次行动不消耗行动机会：攻击后还能再攻击一次，或移动后还能攻击。第一次行动结束时「机动」即消失，但已经给出的额外机会仍然可用。 |
| **固守** | 单位不能被你自己拖动/移动，也不能被「抑制」；但敌方用卡牌效果仍可以把它挪走。 |
| **抢修** | 单位待在后排，整个己方回合既不移动也不攻击，下个己方回合开始时回复全部防御。一旦移动到前线，立刻失去「抢修」。 |

三张示例卡：

- **机动步兵** —— 带「机动」
- **固守步兵** —— 带「固守」
- **战地抢修班** —— 带「抢修」

---

## 二、卡包放在哪里

这个前端**不是**从游戏安装目录下的 `packs` 读取卡包。它从游戏数据目录 `kards/packs` 读取。

### 在编辑器里运行（源码目录 `D:\Godot-orcKsd-main`）

卡包要放在：

```
D:\Godot-orcKsd-main\proto\data\kards\packs\card-pack-bulwark\
```

完整结构：

```
proto\data\kards\packs\
└── card-pack-bulwark\
    ├── manifest.json
    ├── keywords.json
    ├── effects\
    └── cards\
```

这个位置已经放好，直接停止当前运行、再重新运行即可。

### 使用已导出的游戏（`D:\Orc-game`）

已导出的游戏把卡牌数据打包在游戏资源里，启动时会解到用户数据目录，**不会读取 `D:\Orc-game\packs`**。

因此，要让 `D:\Orc-game` 里的游戏带上这个卡包：

1. 确认卡包已经在 `D:\Godot-orcKsd-main\proto\data\kards\packs\card-pack-bulwark`；
2. 重新导出游戏，覆盖到 `D:\Orc-game`（`KardsUi.pck` 与 `data_Kards.Ui_windows_x86_64` 等）；
3. 如果使用补丁更新，把新增的卡包数据一起打进补丁。

`D:\Orc-game\packs` 里的旧副本可以删除，它不会生效。

### 放好后的检查

打开 `card-pack-bulwark` 文件夹，**第一眼就应该能看到 `manifest.json`**。

- 如果打开后看到的是另一个 `card-pack-bulwark` 文件夹，说明多套了一层，删除多余的一层。
- `manifest.json` 里的 `id`（`orc.bulwark`）是卡包身份，不要随便改。
- `manifest.json` 里的 `name` 决定卡包在图鉴里的显示名（当前是「铜墙铁壁系列」）。

---

## 三、让编辑器读取卡包

1. 在编辑器里停止当前运行。
2. 重新运行。
3. 新建一局对局。
4. 打开卡牌图鉴或组卡页面，搜索「机动步兵」「固守步兵」「战地抢修班」。
5. 把这三张卡加入卡组，开始对局。

说明：
- 卡包只在启动时发现；**已经打开的对局不会自动出现新卡**，请新建对局。
- 编辑器控制台如果出现「卡包/插件装载隔离：…」，说明该卡包装载失败，按提示里的包名与原因检查文件。

---

## 四、对局里怎么用

### 机动

1. 让「机动步兵」移动到前线，或者直接攻击。
2. 这次行动结束后，它仍然保有行动机会：可以再攻击一次；如果第一次是攻击，也可以改为移动。
3. 第一次行动结束时，单位身上的「机动」标记就会消失——这是正常的，额外的那次机会已经给你了。用完这次机会后，本回合不能再行动。

提示：如果单位被压制（不能行动），「机动」不会被消耗，压制解除后仍可使用。

### 固守

1. 「固守步兵」上场后，你无法拖动它，也无法把它撤回后排。
2. 敌方用「撤退」这类卡牌效果仍然可以移动它。
3. 对它使用「抑制」不会生效，它的词条与增益不会被清空。

### 抢修

1. 把「战地抢修班」放在后排（支援阵线）。
2. 让它整个己方回合都不移动、不攻击（被攻击、受到伤害不影响；对手回合里被效果挪动也算移动）。
3. 下个己方回合开始时，它的防御回复到满值。
4. 一旦它移动到前线（或被效果挪到前线），「抢修」立即消失，之后不再回复。

## 五、看不到卡或词条不生效时

按顺序检查：

1. **编辑器图鉴里没有三张示例卡**
   - 确认卡包在 `proto\data\kards\packs\card-pack-bulwark\`，`manifest.json` 只隔一层；
   - 确认编辑器是停止后重新运行的；
   - 查看编辑器控制台是否有「卡包/插件装载隔离」提示；
   - 确认新建了对局，而不是在旧对局里找。

2. **已导出的游戏里没有**
   - 这是正常的：`D:\Orc-game\packs` 不会被读取；
   - 需要把 `proto\data` 一起重新导出，或用补丁更新。

3. **卡出现了，但词条没有反应**
   - 确认使用的是带「卡包词条」功能的最新版；
   - 重启后再新建对局（词条在启动时登记，运行中不会注销旧词条）。

4. **词条图标显示了，但效果不对**
   - 确认对局是卡包装载之后新建的；
   - 如果同时装了其他卡包，确认没有另一个卡包使用同名词条（同名词条会被拒绝加载）。

5. **卡包完全没被读取**
   - 确认 `manifest.json` 里的 `kind` 是 `cardpack`；
   - 确认 `guid` 没有被别的卡包占用；
   - 确认 `cards` 文件夹和三张卡文件都在。

## 六、自己改一改

### 改卡名和数值

用记事本打开 `cards` 文件夹里的任意一张卡（例如 `bulwark.mobile-infantry.card.json`）：

- `"name"` 后面引号里的字就是卡名，可以直接改；
- `"attack"` 是攻击力，`"defense"` 是防御力，`"operationCost"` 是行动费用，改冒号后面的数字即可；
- 只改引号里的文字或数字，不要删除大括号、逗号。

改完保存，重新运行编辑器，新建对局。

### 给别的卡加上这三个词条

打开那张卡的文件，在 `keywords` 后面的方括号里加词条名，例如：

```
"keywords": ["机动"]
```

多个词条用逗号隔开：

```
"keywords": ["机动", "固守"]
```

保存、重新运行、新建对局即可。

### 做一张新卡

1. 在 `cards` 文件夹里复制一张现有卡；
2. 把文件名改成新的名字（例如 `my-card.card.json`）；
3. 把文件里的 `"id"` 改成新名字（不能和现有卡重复）；
4. 改 `"name"`、数值和 `keywords`；
5. 保存、重新运行、新建对局。

---

## 七、关于卡包名字

这个卡包在游戏里的标识是 `orc.bulwark`，显示名称是「铜墙铁壁系列」。

- 显示名称改 `manifest.json` 里的 `"name"`；
- `"id"` 是卡包身份，改名会让游戏把它当成另一个卡包（已有卡组里的卡会找不到）。
