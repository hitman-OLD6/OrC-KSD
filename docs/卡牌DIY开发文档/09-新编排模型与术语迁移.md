## 1. 术语迁移表（旧 → 新）

| 旧词（01–08 章、旧资产） | 新词（v4 资产、新模型） | 说明 |
| --- | --- | --- |
| `hooks: ["unit.deployed"]` | **信号** `engine#unit.deployed`（挂载声明 `mounts[]`） | `hooks` 不是"字符串订阅"了，而是"把一个成员挂到某个信号成员上"。前缀转换是纯机械的：`X` → `engine#X` |
| `injects[].target: "伤害处理触发器"`（**显示名**） | **成员地址** `engine#damage-apply` | 显示名寻址整体退役；地址只按**第一个 `#`** 切分，成员名允许含 `.` |
| `injects[].target: "指向触发器"`（卡上的） | `host#targeting` | 卡与 HQ 各有该成员，按当前宿主实例天然消歧 |
| 主触发器（`mainTrigger`） | **组件的成员**（`members[]`） | 一个效果＝一个组件实体；"主逻辑"就是第一条**自有边**，不再有独立于边集合的 "core" |
| `band: Rewrite` / `Veto` / `Apply`、`Commit` | **包装相位** `before` / `before`+`ctx.Stop()` / 外来挂载边 / `after` | band 与接缝全部退役；相位只有 `before`（LIFO）／`after`（FIFO）／`replace`（最后声明者） |
| `seam`（具名动作缝） | （无） | 需要"中间插入"＝**拆成员** |
| `kind: passive/active`、`PassiveEffect`/`ActiveEffect` | （无分类字段） | 一个成员能不能被挂、能不能被调用，由**可见性位标志**决定；不再有主动/被动二分 |
| `disposingTrigger`（隐式兜底） | **框架注销边**（作者不写、也不能写） | 组件装配时自动挂到 `engine#card.destroyed`，位次＝该组件最后一条边 |
| `oneShot: true` | `one-shot: true`（语义由框架承载） | 任一成员首次执行完成后由框架注销整个组件实例 |
| `viewType: "Orc.Game.Damage.DamageApplyView"` | （无此字段） | 视图不再是**类**：成员在 `members[].view.fields[]` 里声明字段；csx 统一 `Func<dynamic, …>` |
| `JudicatorWrapperPrefab` / `judicatorWrappers` | `judge-wraps[]`（同一相位语义、同一注册面） | 判定器包装器与成员包装器共用 `WrapRegistry`（`judicator:<名>` 目标） |

### 1.1 一个最小 v4 组件（对照旧写法）

```jsonc
{
  "schemaVersion": 4,
  "asset": {
    "kind": "component",
    "id": "diy.fire-support",
    "requires-host": "any",          // 允许的宿主类型：unit/order/counter/hq/any
    "active-when": "loaded",         // loaded（在手即生效）/ placed（入场后装配）；缺省 placed
    "one-shot": false,
    "private-fields": [ { "name": "uses", "type": "number", "initial": 0 } ],
    "members": [
      {
        "name": "onPlayed",
        "visibility": ["callable", "mountable"],
        "view": { "fields": [ { "name": "Card", "type": "entity" }, { "name": "Host", "type": "entity" } ] },
        "handler": { "id": "diy.fire-support#onPlayed", "entry": "HandleAsync", "script": "Func<dynamic, Context, CancellationToken, Task> HandleAsync = async (view, ctx, ct) => { … };" }
      }
    ],
    "mounts": [ { "member": "onPlayed", "target": "engine#card.played" } ],
    "wraps":  [ { "handler": "diy.fire-support#mitigate", "target": "engine#damage-apply", "phase": "before" } ],
    "judge-wraps": [ { "judge": "move.leg.eligibility", "phase": "after", "entry": "Handle", "script": "…" } ]
  }
}
```

要点：

- **`members[].visibility`**：`hostable`（可作宿主＝别的成员能挂到我身上）／`mountable`（可被挂到别处）／`callable`（可被跨实体调用）。
  自挂载（`self#…`）不受可见性约束；跨实体挂载两侧都要有相应位。
- **`mounts[]` 只表达顺序，不表达改写**：带 `phase` 的挂载声明＝**通道混用，装载期拒绝**；改写一律走 `wraps[]`。
- **同一组件 prefab 在同一宿主上至多一份实例**：重复引用＝装载期拒绝（需要两份就做两个 prefab）。
- **`requires-host` 是 `host#…` 解析的依据**：组件引用了某宿主类型独有的成员（如 `host#deploy`），
  就必须把 `requires-host` 收窄到该类型；否则装载期报"目标成员不存在"。

## 2. 组件自托管（谁负责装配/注销/一次性）

| 事项 | 谁做 | 作者要不要写 |
| --- | --- | --- |
| 装配时点判定（`active-when`） | 框架（宿主加载 / 入场时按声明装配） | 只声明 `active-when`（缺省 `placed`，且必须显式落成该值） |
| 注销兜底（宿主销毁） | 框架（自动挂 `engine#card.destroyed`，位次＝组件最后一条边） | **不能写**；把 `effect.removed` 当兜底信号＝装载期拒绝（防自触发递归） |
| 一次性（`one-shot`） | 框架（执行前检查、执行后置位，重入安全） | 只声明 `one-shot: true`；**无任何外部可触发边**的 `one-shot` 组件＝装载期拒绝 |
| 复装（回手→再入场） | 框架（销毁旧实例、新建实例、私有字段复位） | 不提供"复用实例重跑初始化"的写法 |
| 边撤销 | 框架（**逐句柄**精确撤销） | 不需要（也不存在"按 owner 扫表"的清理入口） |

**初始化触发器只看定义视图**：可读宿主类型、卡数据声明的词条、预制体声明等**装配期不可变数据**；
不可读血量／场上单位／随机数／回合等对局状态，也不得产生副作用或发事件（API 物理强制，越界编译不过）。

## 3. 作者约束（现在就生效，装载期会拒）

### 3.1 `view` 不得交给 helper 去写（概率性保护）

装载期会做**静态语法检查**（Roslyn 语法树，不是正则）：比对 `view.<Name>` 与 `owner.<Name>` 两条通道的字段声明。
但下面几类写法**不在检查范围内**，只有运行期 setter 闸门兜底：

```csharp
// ❌ 不要这样写：view 交给 helper → 静态检查看不到写入，只有运行期兜底
void Apply(object view) => ((dynamic)view).Amount = 0;

// ❌ 不要这样写：经局部函数/方法传递后再写
void Rescale(dynamic v) => v.Defense -= 1;

// ✅ 可以：直接写（静态检查覆盖）
view.Amount = 0;
view.Defense -= 1;
```

判定口径（唯一契约）：

| 算"写" | 不算 | 别名 |
| --- | --- | --- |
| 直接赋值、`+=`／`-=`／`++`／`--`、作为 `ref`／`out` 实参 | 注释、字符串字面量 | 只追踪**直接**别名（`var v = view; v.X = …`）；经方法/局部函数传递的 `view` **不追踪** |

- `view.<Name>` 只能写视图声明里 `writable: true` 的字段；未声明＝`binding` 失败。
- 私有字段**只能**经 `owner.<Name>` 读写（影子状态，不进数据面）；`view.<私有字段>`＝`binding` 失败。
- **视图字段名与同实体私有字段名不得相同**＝装载期拒绝（两条通道指向同名状态会让读者误判）。

### 3.2 失败分类（看到错误码就知道该改什么）

| 分类 | 含义 | 典型修法 |
| --- | --- | --- |
| `binding` | 静态语法检查失败：`view.<未声明字段>`、写只读字段、`owner.<未声明>` | 改字段名 / 在 `view.fields[]` 声明 / 改走 `owner` |
| `compile` | csx 编译失败（语法、类型、缺 using） | 改脚本 |
| `signature` | 入口签名不符（须四参、返回 `Task`；首参能接收承载视图） | 改签名（统一 `Func<dynamic, Context, CancellationToken, Task>`） |
| `sandbox` | 沙箱策略拒绝（白名单程序集/禁用片段） | 去掉被禁 API |
| `timeout` | 执行超时 | 拆逻辑 |
| `runtime` | 运行期异常 | 按堆栈修 |
| `structure` / `addressing` / `visibility` / `channel` / `timing` / `view` | 装载期结构/寻址/可见性/通道混用/时机/视图字段问题 | 按报告里的地址与成员名改声明 |

**csx 在装载期全量预编译**：编译失败＝**拒绝装载**（不再"隔离记录后继续"）。所以"能装载"⇒"该能跑的都能跑"。

### 3.3 卡包原子性与必需/可选

- **原子**：一个卡包内任一资产（含 csx 预编译）失败＝**整包零注册**，报告列出**全部**失败项（不是首个）。
- **必需包**（`manifest.required: true`）：失败＝**对局不开局**（初始化上抛），且不留半初始化状态。
- **可选包**（缺省）：失败＝**跳过该包**，对局照常开始；被跳过的包在初始化报告与审查导出（`packages[]`）里可见
  （包 id + 失败项 + `skipped` 标记）——作者不会"以为加载了、其实什么都没生效"。

> 社区包语法错误会被放大成"整局不开"——所以**给别人用的包请声明为可选**，官方核心包声明为必需。

## 5. 常见问题

**Q：为什么我写的 `view.Amount = 0` 装载期就报 `binding`？**
`view` 的名字空间＝**数据面（仅视图声明字段）**；`Amount` 没在 `members[].view.fields[]` 里，或在别的成员上声明。
要么在本成员视图里声明它，要么改走 `owner.Amount`（私有字段）。

**Q：`ctx.Stop()` 会回滚已经改过的字段吗？**
不会。`before` 包装器已经写入的值保留在数据面上；停止只让**本成员**的剩余单元（后续外来边、`after`、框架边）不执行，
且**不外溢**到调用方的其它成员。

**Q：为什么 `random` 选择器在我的对局里报错？**
`random` 归引擎随机服务，但**生产对局禁止**（R2c）；只有测试／沙盒／简单 AI 场景经
`MatchOptions.AllowRandomTargeting=true` 显式开启。报错是设计意图——不是"取首个"兜底坏掉了。

**Q：`sel=one` 的效果为什么挂起／报"没有前端接入"？**
`one`／`any` 属**外部裁定**：必须经提交通道（人类 UI／MCP／AI 前端）。引擎不代选；
没有装配 targeter 桥接时**明确失败**（不静默取首个）。确定性选择（`all`／`self`）不需要前端。
