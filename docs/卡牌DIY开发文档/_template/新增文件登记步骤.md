# 新增文件登记步骤

> 本文件是「可扩展约定」的唯一操作说明：新增 = **复制模板 → 按编号命名 → 在 README 登记**。
> 硬规则：**不改既有章节**；新增文件未登记＝文档库不完整（收口检查直接失败）。

## 0. 先判断文件类型

| 你要新增 | 模板 | 目标目录 | 命名 |
| --- | --- | --- | --- |
| 一章主题正文 | [章节模板](./章节模板.md) | `docs/卡牌DIY开发文档/` | `NN-主题.md`（NN 两位、递增） |
| 一个示例 | [示例模板](./示例模板.md) | `docs/卡牌DIY开发文档/examples/` | `NN-<slug>.md` |
| 一张参考表 | 直接建表（无模板） | `docs/卡牌DIY开发文档/reference/` | `<用途>.md`（纯查表、无叙述） |

> 参考表不在模板层复制：表头列固定、条目以代码为真源；新增表须在 README「参考层」表登记。

## 1. 复制模板

1. 复制对应模板文件到目标目录（文件名按上表）。
2. 保留模板的**固定结构**：五件套元信息 / 六段式示例 / 四列表头。
3. 占位段落改写为「该节回答的问题」，**不要留 `TODO`**。

## 2. 按编号命名

- 章：`NN-主题.md`，NN 从 `00` 起两位数字；主题用中文短名（与 README 索引一致）。
- 示例：`NN-<slug>.md`，NN 从 `01` 起；slug 用 ASCII 短横线小写。
- 参考表：中文用途名；不与既有表重名。
- **不重排既有编号**（会打断外链与阅读路径）；新章一律追加到末尾。

## 3. 在 README 登记（两处都要）

1. **全量索引**：在对应小节的表格追加一行（编号 / 链接 / 主题 / 状态）。
2. **章节状态表**：追加一行，状态初始为 `草稿`（示例为 `未开始` 直至证据可复跑）。
3. 若新增的是示例：同时更新 `examples/README.md` 的示例表（该文件由 S18 建立）。

## 4. 提交前自检

- [ ] 五件套/六段式齐全且非空（无 `TODO`、无空占位标题）
- [ ] 每个结论能在 `reference/_anchors.md` 找到符号名；查不到的内容已删除
- [ ] 相对链接逐条可解析（`test -f` 全部通过）
- [ ] README 两处登记完成；未改动既有章节的正文
- [ ] 若含命令：命令已在本地复跑，输出写入文件

## 5. 状态推进

| 从 | 到 | 条件 |
| --- | --- | --- |
| 未开始 | 草稿 | 正文主体完成、五件套齐全 |
| 草稿 | 完成 | 本章自检项全部可勾选 |
| 完成 | 证据已跑 | 文内命令最近一次复跑通过（记录日期与输出） |

> 状态只升不降；代码演进导致命令失效时，退回「完成」并在文件内标注失效原因，待修复后重新升为「证据已跑」。
