# 示例模板

> 复制本文件 → 命名为 `examples/NN-<slug>.md` → 在 `examples/README.md` 与 [README](../README.md) 索引登记。
> 一例一文件、可单独阅读与复制；**六段缺一段即不合格**。

## 使用方式

1. 复制到 `docs/卡牌DIY开发文档/examples/NN-<slug>.md`（NN＝`01`…`08`）。
2. 先填「卡面文本」，再填「机制选型」，然后才是代码/数据。
3. 证据段必须写**可复跑命令 + 预期输出 + 证据等级**；跑不出预期输出的示例不得标「完成」。
4. 数据侧落 `samples/card-pack-diy/`，代码侧落 `tests/Orc.Game.Tests/`；两者都要在示例内写实体路径。

## 质量门禁

| 项 | 不合格的样子 | 合格的样子 |
| --- | --- | --- |
| 卡面 | 改写成「大概意思」 | 原文逐字保留 |
| 选型 | 只写「用 csx」 | 给判据与替代方案 |
| 代码 | 片段缺 using / 缺方法体 | 整文件可复制、可编译/可解析 |
| 时序 | 只写「然后触发」 | 每步有符号名 |
| 坑 | 只写「注意」 | 错写法 → 症状 → 排查分支 |
| 证据 | 「应该可以」 | 命令 + 预期输出 + 等级 + 实体路径 |

## 与正文的关系

- 示例内不重复机制原理：用一句话 + 链接指向 01–07 的对应小节。
- 示例是「可复制品」；机制解释以章节为准。改机制口径时，先改章节，再回改示例。
