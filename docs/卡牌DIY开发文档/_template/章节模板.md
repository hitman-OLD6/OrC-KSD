# 章节模板

> 复制本文件 → 按编号命名（`NN-主题.md`）→ 在 [README](../README.md) 的「全量索引」与「章节状态表」登记。
> **不改既有章节**；新增章节必须与本模板同构（元信息块 + 正文结构 + 自检位）。

## 使用方式

1. 复制到 `docs/卡牌DIY开发文档/NN-主题.md`（NN＝下一个两位编号）。
2. 替换标题与五件套；正文按「四段式」展开（是什么 / 何时用 / 完整 API 表 / 最小片段 + 边界）。
3. 每个结论给出**符号锚点**（`reference/_anchors.md` 的符号名）；查不到符号的内容不得写入正文。
4. 在 README 两处登记（索引表 + 状态表），状态初始为「草稿」。
5. 自检项逐条勾选后，状态才可改为「完成」；文内命令可复跑后改为「证据已跑」。

## 写作约束

- **代码是唯一真源**：签名/路径/字段名以 `src/` 现状为准；不得描述未实现能力。
- **两条路径标注**：每个机制段落末尾标「数据侧可达 / 仅代码侧可达」。
- **来源两面口径**：`Source`＝事件引发者（载荷、只读、可空）；`TriggerCard`＝当前 handler 的触发者（帧值、链上最后者胜）。handler 内再发信号传 `source: view.TriggerCard`。
- **不写 TODO**：占位段落写「该节回答的问题」，不要留 `TODO` 字样。
- **链接**：章内链接用相对路径；跨章链接必须指向已存在的文件（提交前跑一次链接自检）。
