# 示例 01：火力支援（R6a）

## 1. 卡面文本

> 对一个敌方单位造成 3 点伤害；本方总部 +5 防御。

## 2. 机制选型

- 承载：**组件资产 + csx**（数据侧）
- 触发点：`engine#card.played`（`view.Card` ＝ 本卡；`view.Host` 过滤自身）
- 动作面：`SelectAsync("one","enemy")` → `DamageAsync(target, 3, source, ct)`；`BuffAsync(hq, 0, 5, Permanent, ct, source)`
- 判据：一次伤害 + 一次修饰，无需改规则/流程；数据侧足够。
- 路径可用性：**数据侧可用**；证据等级：**L2（行为用例通过）** + 卡包预检 L1。

## 4. 触发时序

| 步 | 发生什么 | 符号 |
| --- | --- | --- |
| 1 | 玩家打出指令（预打出 → 复验 → 施放） | `PlayManager.PlayOrderAsync` |
| 2 | **`Counter` 段**：反制检查（默认无处理器；反制命中＝`Stop`，跳过后续 `Resolve`） | `engine#order.cast` |
| 3 | **`Resolve` 段**：发射 `card.played`（被反制时不发） | `OrderFlow` → `GameUpdates.EmitCardPlayed` |
| 4 | 本组件的 `onPlayed` 边被调用，`view.Host` 命中本卡 | `OrchestrationEntity.ExecuteMemberAsync` |
| 5 | 无头选一个敌方单位 | `EffectRuntime.SelectAsync` |
| 6 | 造成 3 点伤害（`Source`＝本卡） | `EffectRuntime.DamageAsync` |
| 7 | 本方总部 +5（HQ 走 `HqHealth` 字段） | `EffectRuntime.BuffAsync` |
| 8 | **`Finalize` 段**：扣费 → 离手（`Stop` 不阻止本段） | `engine#order.finalize` |

## 5. 边界与坑

- **必须过滤 `view.Host`**：`card.played` 对所有卡发射；漏掉过滤＝对方打牌也会触发。
- 「单目标」用**外部裁定**（`SelectAsync` 的 `sel: "one"`）——需要前端接入；没有前端时**明确失败**，不会静默取首个。
  想完全离线可跑，用确定性选择器（`all` / `self`）。
- HQ 加防走 `BuffAsync(hq, 0, N, ...)`：`attack=0` 时游戏层映射到 `HqHealth`；传 `attack≠0` 会返回 `false`。
- 原生指令卡**已可被反制**（G-01 已解决）：反制命中默认 `ctx.Stop()`——指令**照常扣费、照常离手**，只是 `Resolve` 段的效果不触发；只有需要「牌留手、不扣费」的严格中断时才用 `ctx.Interrupt()`（见示例 6）。
- **被反制的指令不发 `card.played`**（视为未成功打出），但仍扣费离手——本效果挂在 `card.played` 上，因此反制命中时不会触发。
- `Source` 传本卡：下游 `card.damaged`/`card.died` 的 `Source` 仍为 null（G-04），但 `Killer`/`Unit` 已归属。
