# 示例 02：齐射（R6b / D3）

## 1. 卡面文本

> 将 3 点伤害随机分配给场上单位。

## 2. 机制选型

- 承载：**效果预制体 + csx**（数据侧）
- 触发点：`card.played`（本卡）
- 动作面：`SelectAsync("random", side: null, count: 1)` ×3 → `DamageAsync(target, 1, source, ct)`
- 判据：分配规则可表示为「逐点独立随机」；不需要新判定器。
- D3 口径：**总值 3 点，逐点独立随机指派给一个存活单位（可重复命中）**；无单位＝零伤害；有单位时总伤害恒为 3。
- 路径可用性：**数据侧可用**；证据等级：**L2** + 卡包预检 L1。

## 4. 触发时序

| 步 | 发生什么 | 符号 |
| --- | --- | --- |
| 1 | 打出指令 → `card.played` | `GameUpdates.EmitCardPlayed` |
| 2 | 本效果命中（`view.Host`） | `Trigger.RunEventsAsync` |
| 3 | 第 1 点：随机取 1 个单位 | `SelectAsync("random", …, count: 1)` |
| 4 | 造成 1 点伤害 | `DamageAsync(..., 1, ...)` |
| 5 | 重复 2 次（可命中同一单位） | 同上 |
| 6 | 无候选 → 提前结束（零伤害） | `picked.Count == 0` |

## 5. 边界与坑

- **不是「均分」**：D3 的语义是逐点随机（可重复命中）。若卡面要求「均分」，把循环改成
  「先取全部单位，再 `每人 1 点`，余数从前往后补」——这是**另一条**规则，不要混用。
- `side: null` ＝双方单位都算（含己方）；只打敌方改 `"enemy"`。
- 伤害逐点施加：若第一点击杀某单位，后续随机候选会自动排除（已死亡/离场不在候选）。
- 「3 点」写死在 csx 里；要做「X 点」需从卡面参数/数据传入（当前 prefab 无参数字段，属数据侧边界）。
- 无单位时 `SelectAsync` 返回空集 → 循环 `break`，零伤害（与 D3 一致）。
