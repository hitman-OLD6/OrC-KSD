# 示例 04：轰炸机压制（R6d）

## 1. 卡面文本

> 每有一个敌方轰炸机，本单位 +1 攻击。

## 2. 机制选型

- 承载：**C# 声明**（代码侧）——`PrefabDefinition` 声明组件，成员 handler 是 C# 方法而不是 csx
- 触发点：`engine#card.load`（加载期注册一次）——之后靠**光环重跑**随动，不再需要信号
- 动作面：`AuraRegistry.Register(new AuraDeclaration(...))` ＋ `RerunAurasAsync(host)`
- 判据：持续、随场上集合变化的数值；一次 `BuffAsync` 会错过后续变化。
- **为什么数据侧做不到**（这是本示例的真正价值）：
  1. csx 沙箱**屏蔽 `Environment` 片段**（文本级过滤，`GameEnvironment` 也命中），所以脚本里读不到战场集合；
  2. `EffectRuntime.OwnerUnits(host)` 只给「己方单位」，数不到敌方；
  3. `EffectRuntime.Judge(...)` 只能两两判定，不能枚举。
  ⇒ 「每有一个敌方 X」必须在 C# 里数。
- 路径可用性：**仅代码侧可用**；证据等级：**写法参考**（原 `DiyExample04_*` 用例已随旧 `Effect` 类移除）。

## 3. 完整代码

**① 声明组件**（装配期注册进 `PrefabCatalog`）：

```csharp
using Orc.Core.Model;

var prefab = new PrefabDefinition(
    "diy.bomber-suppress.aura",
    EntityKind.Component,
    requiresHost: HostKind.Any,
    members: new[]
    {
        new MemberDefinition(
            "onLoad",
            ViewSpec.Empty,                                   // 不读载荷
            MemberVisibility.All,
            new[] { new OwnedEdge(MemberEdges.For<CardEventView>(OnLoad)) })
    },
    mounts: new[] { new MountDeclaration("engine#card.load", "onLoad") },
    activeWhen: ActiveWhen.Loaded,                            // 加载期信号 ⇒ 必须 loaded
    oneShot: false);
```

**② 成员 handler**（普通 C# 方法，可以自由读 `GameEnvironment`）：

```csharp
using Orc.Cards;
using Orc.Game.Board;
using Orc.Game.Cards;
using Orc.Game.Effects;

private async Task OnLoad(CardEventView view, Context ctx, CancellationToken ct)
{
    if (view.Host is not Card self || !ReferenceEquals(view.Card, self))
    {
        return;
    }

    var runtime = EffectRuntime.ResolveFor(self);
    if (runtime?.AurasOf(self) is not { } auras)
    {
        return;
    }

    if (GameEnvironment.ResolveFor(self) is not { } env)
    {
        return; // 脱局：降级不抛
    }

    auras.Register(new AuraDeclaration(
        self,
        CardStatFields.Attack,
        (_, current) => current + CountEnemyBombers(self, env),   // 每轮重跑现数
        self,                                                    // 来源标记（卸载整组撤销）
        (_, beneficiary) => ReferenceEquals(beneficiary, self))); // 只加成自己

    await runtime.RerunAurasAsync(self, ct);                     // 立刻生效一轮
}

private static int CountEnemyBombers(Card host, GameEnvironment environment)
{
    if ((host as CardBase)?.Owner is not { } owner)
    {
        return 0;
    }

    var count = 0;
    foreach (var line in new[]
             {
                 environment.Battlefield.PlayerASupportLine,
                 environment.Battlefield.PlayerBSupportLine,
                 environment.Battlefield.FrontLine,
             })
    {
        foreach (var slot in line)
        {
            if (slot.Occupant is UnitCard unit
                && !ReferenceEquals(unit.Owner, owner)
                && unit.Definition.UnitTypes.Contains("bomber"))
            {
                count++;
            }
        }
    }

    return count;
}
```

## 4. 触发时序

| 步 | 发生什么 | 符号 |
| --- | --- | --- |
| 1 | 宿主加载，组件装配（`active-when: loaded`）→ 收到 `card.load` | `OrchestrationRuntime.Bind` |
| 2 | handler 注册光环（transform 闭包捕获 `env` 与 `runtime`） | `AuraRegistry.Register` |
| 3 | 立刻手动重跑一次，让当前场面生效 | `RerunAurasAsync` |
| 4 | 单位部署/离场 → `unit.deployed`/`card.died` → 环境事件驱动**全卡重跑** | `GameEnvironment.IsRerunTrigger` → `RerunAllCardsAsync` |
| 5 | 重跑时调 `transform`：现数敌方轰炸机 → 叠加到攻击 | `AuraDeclaration.Transform` |
| 6 | 轰炸机阵亡 → 重跑 → 数值回落 | 同上 |

## 5. 边界与坑

- **`Transform` 只有 `(受益卡, 当前值)`**，拿不到环境——必须像示例一样在 handler 里把 `GameEnvironment` 闭包进去（只有 C# 能这么做）。
- **收益对象 ≠ 计数对象**：`predicate` 筛的是「谁受益」（本例只有自己）；「数谁」要在 transform 里自己写。
- 光环注册**不等于**立即生效：注册后要等一轮重跑。所以示例在注册后立刻调了一次 `RerunAurasAsync`。
- **不要自己登记 teardown**：v4 里光环随组件实例卸载撤销（逐句柄），没有 `OnUnmount` 可写。
- 计数型加成只随「全域重跑」刷新；如果某个变更不触发重跑（自定义信号），数值不会自动刷新——那种情况才需要再加一条监听边手动 `RerunAurasAsync`。
- **别试图把它写成 csx**：`Environment` 在沙箱屏蔽清单里（文本级子串匹配），`GameEnvironment` 会一起被拒。这是本示例必须走代码侧的根本原因。
