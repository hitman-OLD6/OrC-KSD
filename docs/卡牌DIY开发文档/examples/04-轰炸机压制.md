# 示例 04：轰炸机压制（R6d）

## 1. 卡面文本

> 每有一个敌方轰炸机，本单位 +1 攻击。

## 2. 机制选型

- 承载：**C# 效果 + 光环**（代码侧）
- 触发点：无显式信号——光环在**每轮链重跑**时现收集（入场/离场/死亡均触发全域重跑）
- 动作面：`AuraRegistry.Register(AuraDeclaration)`；或 `EffectRuntime.DeclareAuraAsync`
- 判据：持续、随场上集合变化的数值；一次 `BuffAsync` 会错过后续变化。
- 路径可用性：**仅代码侧可用**（数据侧只能做静态近似）；证据等级：**L2**。
- **两条写法**：
  - A. `DeclareAuraAsync`：delta 是**静态值**（例如 +1），无法表达「每有一个」；
  - B. 自定义 `AuraDeclaration`：`transform` 里现数敌方轰炸机（本示例采用）。

## 3. 完整代码

**B（推荐，随动）**：

```csharp
using Orc.Cards;
using Orc.Core;
using Orc.Game.Board;
using Orc.Game.Cards;

public sealed class BomberCountAuraEffect : PassiveEffect
{
    public BomberCountAuraEffect()
        : base("轰炸机计数光环")
    {
    }

    protected override void OnMount()
    {
        var environment = GameEnvironment.ResolveFor(Host);
        if (environment is null)
        {
            return; // 脱局/未装配：不注册（降级不抛）
        }

        var declaration = new AuraDeclaration(
            Host,
            CardStatFields.Attack,
            (_, current) => current + CountEnemyBombers(Host, environment), // 每轮重跑现数
            this,                                                           // 来源标记（卸载整组撤销）
            (_, beneficiary) => ReferenceEquals(beneficiary, Host));         // 只加成自己

        environment.Auras.Register(declaration);
        AddTeardownRegistration(() => environment.Auras.RemoveBySource(this));
    }

    private static int CountEnemyBombers(Card host, GameEnvironment environment)
    {
        if ((host as CardBase)?.Owner is not { } owner)
        {
            return 0;
        }

        var count = 0;
        foreach (var line in new[]
                 {
                     environment.Battlefield.PlayerASupportLine,
                     environment.Battlefield.PlayerBSupportLine,
                     environment.Battlefield.FrontLine,
                 })
        {
            foreach (var slot in line)
            {
                if (slot.Occupant is UnitCard unit
                    && !ReferenceEquals(unit.Owner, owner)
                    && unit.Definition.UnitTypes.Contains("bomber"))
                {
                    count++;
                }
            }
        }

        return count;
    }
}
```

**A（静态近似，不随动）**：

```csharp
// 只给「所有友方步兵」+1；与敌方轰炸机数量无关——这就是静态 delta 的边界。
await runtime.DeclareAuraAsync(
    host,
    field: "attack",
    delta: 1,
    filter: new EffectAuraFilter(Side: "friendly", UnitType: "infantry"),
    ct: ct);
```

## 4. 触发时序

| 步 | 发生什么 | 符号 |
| --- | --- | --- |
| 1 | 宿主入场，效果装载 → `OnMount` 注册光环 | `AuraRegistry.Register` |
| 2 | 部署单位 → `unit.deployed`/`unit.joined` | `GameUpdates` |
| 3 | 环境事件驱动**全卡重跑** | `GameEnvironment.IsRerunTrigger` → `RerunAllCardsAsync` |
| 4 | 重跑时收集命中声明，调用 `transform` | `CollectAuras` |
| 5 | 现数敌方轰炸机 → 叠加到攻击 | `AuraDeclaration.Transform` |
| 6 | 轰炸机阵亡 → `card.died` → 重跑 → 数值回落 | 同上 |

## 5. 边界与坑

- **`Transform` 只有 `(受益卡, 当前值)`**，拿不到环境——必须像示例一样在 `OnMount` 捕获 `GameEnvironment` 再闭包计数。
- **收益对象 ≠ 计数对象**：`EffectAuraFilter` 筛的是「谁受益」（本例只有自己）；「数谁」要在 transform 里自己写。
- 光环注册**不等于**立即生效：注册后要等一轮重跑；宿主未在场时被通用门禁拦截。
- 必须登记 teardown（`RemoveBySource(this)`），否则效果销毁后声明残留。
- 数据侧只有静态近似（A）；要「每有一个」必须上代码（本示例 B）。
- 计数型加成随「全域重跑」触发；如果某个变更不触发重跑（自定义信号），数值不会自动刷新。
