# 示例 05：战地救护（R6e / R9）

## 1. 卡面文本

> 友方因敌方弃牌时，从卡组抽取此牌。

## 2. 机制选型

- 承载：**组件资产 + csx**（数据侧）
- 触发点：`engine#card.discarded`（读 `view.Source` 判「敌方所致」）
- 动作面：`FetchFromDeckAsync(self, ct, self)`（从卡组定向取回自身）
- 判据：需要归因而非仅事件；`Source` 已由 R9 提供，数据侧可判。
- 路径可用性：**数据侧可用**（依赖调用方传 `source`）；证据等级：**L2** + 卡包预检 L1。

## 4. 触发时序

| 步 | 发生什么 | 符号 |
| --- | --- | --- |
| 1 | 敌方效果对友方手牌执行弃置 | `PlayerManager.DiscardCardAsync(player, card, ct, source: enemyCard)` |
| 2 | 移除 → 销毁 → 发 `card.discarded`（载荷含 `Source`） | `HandLimitBurn.DestroyAndEmitDiscardedAsync` |
| 3 | 本组件的 `onDiscarded` 边被调用；`view.Source`＝敌方施动卡 | `OrchestrationEntity.ExecuteMemberAsync` |
| 4 | 比较归属：`sourceOwner != selfOwner` → 敌方所致 | csx |
| 5 | 从卡组取出自身 → 进手牌（`card.drawn` → `card.hand.add`） | `EffectRuntime.FetchFromDeckAsync` |

## 5. 边界与坑

- **必须有 `source`**：`DiscardCardAsync(..., source)` 不传时 `view.Source == null` → 本效果不触发（这正是「不猜测、不回退」）。
- **不要用 `view.TriggerCard` 判敌方**：本效果挂在自身组件上，`TriggerCard` 解析出来就是自己。
- 若弃置由**己方**造成（`source` 是己方卡），归属比较会拒绝 → 双向语义成立。
- 卡在**卡组**才可取回；若已被抽到手里，`FetchFromDeckAsync` 返回 `Rejected`（不抛）。
- 取回是「单张」：多张同名卡需各自有独立组件实例（本卡按实例监听）。
- 依赖 R9 的 `Source` 写法；早于 R9 的旧文档/示例不再适用。
