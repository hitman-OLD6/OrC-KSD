# 示例 07：指令免疫（R6g）

## 1. 卡面文本

> 使一个单位无法被指令指向。

## 2. 机制选型

- 承载：**判定器包装（`TargetingDeclaration`）** 或 **词条程序 `targeting.forbid`**（混合）
- 触发点：目标候选名单判定器 `targeting.candidate.eligibility` 的 After 段（从名单剔除）
- 动作面：无（纯过滤，不产生状态变更）
- 判据：这是「能不能被选」的规则改写，不是「发生什么」。
- 路径可用性：
  - **仅代码侧可用**：`TargetingDeclaration`（C#，生命周期由效果负责）；
  - **混合**：词条程序 JSON（规则点）＋ 一行 `ProgramKeywordComponent.Register` 注册词条标识。
- 证据等级：**L2**（两条路径各有用例）。

## 3. 完整代码

**路径 A · 代码侧声明**：

```csharp
using Orc.Game.Cards;

var declaration = new TargetingDeclaration(
    match.Judicators,
    guarded,                                        // 被保护单位
    candidate => ReferenceEquals(candidate, guarded),// 保护范围
    () => true,                                      // 在场判定（离场自动失效）
    sourceKind: "command");                          // 只挡指令

declaration.Attach(enemyPlayer.Index); // 挂到「敌方指令」的候选域
// ……
declaration.Detach();                  // 效果卸载时撤销（幂等）
```

**路径 B · 词条程序（混合）**：

```csharp
using Orc.Game.Cards;

// ① 注册词条程序（必须早于建局：对局在 Initialize 时冻结词条快照）
ProgramKeywordComponent.Register(
    "diy.example7.forbid",
    KeywordProgram.Parse(
        """
        {
          "schema": 1,
          "rules": [
            { "rule": "targeting.forbid", "scope": "self", "value": "1", "source": "command" }
          ]
        }
        """));

// ② 把词条授予被保护单位（组件挂载时自动 Attach 到对手域）
await guarded.Keywords.GrantAsync("diy.example7.forbid");
```

## 4. 触发时序

| 步 | 发生什么 | 符号 |
| --- | --- | --- |
| 1 | 敌方指令发起选靶，求候选名单 | `JudicatorSelectionRule.Candidates` |
| 2 | 判定器产出全量候选 | `TargetingEligibility` |
| 3 | After 包装器过滤：被保护者剔除（仅敌方来源、仅 `command`） | `TargetingDeclaration.Filter` |
| 4 | 前端只看到过滤后的候选 | targeter |
| 5 | 来源离场/词条移除 → `_isActive` 为 false → 不再过滤 | 兜底 |

## 5. 边界与坑

- **`value` 必须非 0**：词条程序的 `targeting.forbid` 规则以 `NumberFor(rule.Value) == 0` 判定跳过；写 `"value": "0"` ＝不生效。
- **注册时机**：`ProgramKeywordComponent.Register` 必须早于 `Match.Initialize`（对局冻结词条快照，事后注册会 fail-fast）。
- **`sourceKind` 语义**：`command` 只挡指令；`unit-effect` 挡单位效果；`any` 都挡。声明对手域＝**施动方**玩家域（`Attach(caster.Index)`）。
- `TargetingDeclaration` 不自动调度生命周期：装配期 `Attach` 拿到 `IDisposable`，组件卸载时 Dispose 即撤销（没有 `OnUnmount` 可写）。
- 只影响**候选名单**；已经提交的非法目标由提交侧复核（`IsEligible`）兜底。
- 数据侧纯 JSON 做不到：必须有一个代码侧注册动作（混合）。
