# 示例 08：突袭推进（R6h）

## 1. 卡面文本

> 把指定单位加入己方支援阵线，然后随机和一个敌方单位战斗；若其存活且前线没有敌方单位，使其移到前线，并对敌方总部造成 3 点伤害；否则使其撤退。

- **括号里的条件是「推进条件」，不是「阵亡条件」**：存活且前线无敌人 → 推进；存活但前线有敌人 → 撤退；阵亡 → 终止。
- 「撤退」按引擎 `retreat` 语义落在**己方支援线空槽**，不是回手牌。

## 2. 机制选型

- 承载：**C# 效果 + 流程编排**（代码侧）
- 触发点：指令卡打出后由效果显式执行（不是「单位入场」信号）——因为加入路径本身不发部署信号
- 动作面：`PlayManager.JoinUnitAsync` → `SelectAsync("random","enemy")` → **`EffectRuntime.BattleAsync`**（R10）→ `MoveAsync("frontline")` / `CommandManager.MoveUnitAsync(unit, slot)`
- 判据：三段分支 + 强制的「战斗」（快照攻击力、同时结算）——数据侧没有「战斗」动作，也没有分支后的位移编排。
- 路径可用性：**仅代码侧可用**；证据等级：**L2（三条分支各一条用例）**。
- **战斗入口的选择**（R10 起已收口）：

| 方案 | 战斗语义 | 能否表达三分支 | 结论 |
| --- | --- | --- | --- |
| **A. `EffectRuntime.BattleAsync`（本示例）** | 快照＋同时结算；`battle.damage` → `damage.apply`；无射程/守护/伏击/反击资格 | 能 | **唯一推荐** |
| B. 词条程序 `attack` 操作 | 真实指挥对战（走 `internal` 的 `AttackByEffectAsync`，含射程/守护判定） | 不能：战斗后的「存活→推进/撤退」分支写不进词条程序 | 只用于「单纯打一下」 |
| C. 两向 `DamageAsync` | 近似（需自己快照；无同时结算语义） | 能 | 已过时：G-02 由 R10 关闭，不要再手写 |

> `engine.AttackFlow.ExecuteAsync` **仍不能**当游戏层战斗：它默认的「伤害生效」处理器扣的是内核 `HealthData`，游戏层单位没有该组件（事件被隔离，零伤害）。

## 3. 完整代码

**① 指令效果入口：加入 + 流程**

```csharp
using Orc.Cards;
using Orc.Game;
using Orc.Game.Cards;
using Orc.Game.Managers;

// caster＝施放本指令的卡；unit＝被指定的单位（已在手牌或场上）
var owner = (caster as CardBase)?.Owner;
if (owner is null)
{
    return;
}

// 加入路径：放进己方支援线空槽——不扣部署费、不走部署词条、不发部署信号。
var slot = match.Battlefield.GetSupportLine(owner).First(candidate => candidate.IsEmpty);
var joined = await match.PlayManager.JoinUnitAsync(unit, slot, ct);
if (joined.Status != PlayResultStatus.Success)
{
    return; // 无空槽 / 已单位化：整段流程不执行
}

var outcome = await AssaultFlow.RunAsync(match, unit, ct);
```

**② 突袭流程（三分支）**

```csharp
using Orc.Cards;
using Orc.Core;
using Orc.Game;
using Orc.Game.Cards;
using Orc.Game.Effects;

public enum AssaultOutcome
{
    NoTarget,
    Died,
    Advanced,
    Retreated,
}

public static class AssaultFlow
{
    public static async Task<AssaultOutcome> RunAsync(Match match, UnitCard unit, CancellationToken ct = default)
    {
        if (EffectRuntime.ResolveFor(unit) is not { } runtime)
        {
            return AssaultOutcome.NoTarget; // 脱局：静默降级，不抛
        }

        // ① 随机一个敌方单位（无候选＝不执行；卡面未定义该分支）。
        var picked = await runtime.SelectAsync(unit, new EffectSelector("random", "enemy", null, null, null, 1));
        if (picked.Count == 0)
        {
            return AssaultOutcome.NoTarget;
        }

        var target = picked[0];

        // ② 强制战斗：R10 的 BattleAsync——快照双方攻击力后同时结算（先死者不影响反向输出）；
        //    无射程/守护/伏击改写/反击资格判定；不扣行动费、不清行动位、不发攻击类信号。
        await runtime.BattleAsync(unit, target, source: unit, ct);

        // ③ 阵亡分支：终止（不移动、不伤害）。
        if (unit.GetData<UnitStateData>().IsDestroyed)
        {
            return AssaultOutcome.Died;
        }

        var owner = unit.Owner!;
        var enemy = match.Players.First(player => !ReferenceEquals(player, owner));

        // ④ 推进条件＝前线无存活敌方单位。
        var enemyOnFront = match.Battlefield.FrontLine.Any(candidate =>
            candidate.Occupant is CardBase occupant
            && ReferenceEquals(occupant.Owner, enemy)
            && !occupant.GetData<UnitStateData>().IsDestroyed);

        if (!enemyOnFront)
        {
            await runtime.MoveAsync(unit, "frontline", ct, unit);
            await runtime.DamageAsync(enemy.Hq, 3, unit, ct);
            return AssaultOutcome.Advanced;
        }

        // ⑤ 否则撤退：移回己方支援线空槽（不是回手牌）。
        var destination = match.Battlefield.GetSupportLine(owner).First(candidate => candidate.IsEmpty);
        await match.CommandManager.MoveUnitAsync(unit, destination, ct);
        return AssaultOutcome.Retreated;
    }
}
```

## 4. 触发时序

| 步 | 发生什么 | 符号 |
| --- | --- | --- |
| 1 | 指令打出，效果在**指令施放链**的 `Resolve` 段执行 | `engine#order.cast` |
| 2 | 选定单位加入己方支援线空槽（不扣费、不发部署信号） | `PlayManager.JoinUnitAsync` |
| 3 | 无头选靶取一个敌方单位 | `EffectRuntime.SelectAsync` |
| 4 | 快照双方攻击力 → 同时结算（先死者不影响反向输出） | `EffectRuntime.BattleAsync`（`battle.damage` → `damage.apply`） |
| 5 | 我方阵亡 → 终止（`card.died` 留痕，位置清空） | `UnitStateData.IsDestroyed` |
| 6 | 前线无敌方存活单位 → 移前线 + 敌方 HQ −3 | `MoveAsync("frontline")`、`DamageAsync(hq,3,unit)` |
| 7 | 前线有敌方存活单位 → 移回己方支援线空槽 | `CommandManager.MoveUnitAsync(unit, slot)` |
| 8 | 指令收尾（扣费、离手；反制 `Stop` 也照常执行本段） | `engine#order.finalize` |

## 5. 边界与坑

- **`BattleAsync` ≠ 指挥对战**：它不做射程/守护/烟幕/拦截/伏击改写/反击资格判定，也不扣行动费、不清行动位、不发 `unit.attack.*`/`unit.combat.survived`/`unit.acted`。卡面若写「交战」要说明是哪种。
- **`AttackFlow` 不是战斗动作面**：其默认伤害处理器扣内核 `HealthData`；游戏层单位吃不到 ⇒ 零伤害且被事件隔离。用 `BattleAsync`，不要绕回去。
- **`AttackByEffectAsync` 仍是 `internal`**：词条程序内部能用（B），作者代码用不了；需要真实指挥对战时才用它，不要反射绕。
- **免疫会吃掉战斗伤害**（R11 行为变更）：`BattleAsync` 也走 `damage.apply`，所以「免疫」单位在战斗里同样不掉血；重甲则**不**减战斗伤害。
- **`MoveAsync("frontline")` 不受行动门禁、也不花行动**（S6/R16：代价属于「指挥」，效果移动免费）：不扣指挥点、不动 `CanMove`/`CanAttack`、不发 `unit.acted`、不被「被压制」阻断。推进/撤退都是纯效果位移，测试里无需额外的行动激活步骤。
- **撤退只能用 `MoveUnitAsync(unit, slot)`**：限「己方支援线**空槽**」；无空槽会返回 `false`（不抛）。必须先 `First(IsEmpty)` 拿到槽位。两个重载（`Slot` / `zone`）都免费：不扣指挥点、不动行动位、不发 `unit.acted`、不受压制阻断。
- **阵亡判定要读 `UnitStateData.IsDestroyed`**，不要读 `Defense <= 0`（修饰器可能还没回落）。
- **同时结算**：`BattleAsync` 先快照双方攻击力再依次施加，所以先死一方仍会打出伤害（同归于尽可行）。这与旧写法「目标死了就不反击」不同——本示例采用引擎语义。
- **加入路径不发部署信号**：`JoinUnitAsync` 走「加入触发器」而非部署链，所以「部署时」类效果不会因这次加入触发——这是有意为之（R6h 建模前提）。
- **`SelectAsync` 的 `random` 是无头选靶**：生产对局默认禁止随机（R2c），需 `MatchOptions.AllowRandomTargeting`；要玩家点选则把 `sel` 改成 `one`／`any`（走提交通道）。
- 数据侧做不到本示例：纯 JSON 没有「战斗」动作，也没有「按存活分支走不同位移」的编排。
