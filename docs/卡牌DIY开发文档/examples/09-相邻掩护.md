# 示例 09：交叉掩护（相邻友方步兵：行动花费 -1、受到的伤害 -1）

## 1. 卡面文本

> 相邻友方步兵的行动花费减一，受到的伤害减一。

## 2. 机制选型

- 承载：**两个效果预制体 ＋ csx**（数据侧），底层能力＝光环（Aura）＋ 伤害处理端改写。
- 触发点：
  - 行动花费 → **无信号**：`card.load` 时一次性登记 `AuraDeclaration`（光环路：受益侧重跑时现收集）；
  - 受到的伤害 → `damage.apply`（伤害处理端，`ActionHandleBands.Rewrite` 段），经 `injects` 注入。
- 动作面：`EffectRuntime.AurasOf` / `RerunAurasAsync`（光环声明）、`EffectRuntime.Judge`（判定器组合）、
  直接改 `DamageApplyView.Amount`。
- 判据：
  - **行动花费**是持续态数值 → 必须走光环（一次性 `BuffAsync` 会在位置变化后失真，见 [04](./04-轰炸机压制.md)）；
  - **受到的伤害**不是卡的字段，修饰链无此维度 → 只能在伤害管线的处理端改写 `Amount`；
  - 「相邻 + 友方 + 步兵」拆成三个**通用判定器**组合，卡面条件可被插件整体替换（不改卡）。
- 路径可用性：**数据侧可用**（纯 JSON + csx，无需改 C#）。

## 3. 完整数据

### 3.2 光环预制体（`samples/card-pack-diy/effects/diy.adjacent-cover.aura.prefab.json`）


csx 展开（对照阅读；写进 JSON 时须压成 `\n`/`\"` 转义形态）：

```csharp
Func<Orc.Cards.CardEventView, Context, CancellationToken, Task> HandleAsync = async (view, ctx, ct) =>
{
    if (view.Host is not Orc.Cards.Card self || view.Card is not Orc.Cards.Card loaded)
    {
        return;
    }

    if (!object.ReferenceEquals(loaded, self))
    {
        return; // 只处理本卡的加载事件
    }

    var runtime = Orc.Game.Effects.EffectRuntime.ResolveFor(self);
    var auras = runtime is null ? null : runtime.AurasOf(self);
    if (runtime is null || auras is null)
    {
        return; // 未装配：功能不可用、不抛错
    }

    auras.Register(new Orc.Game.Cards.AuraDeclaration(
        self,
        Orc.Game.Cards.CardStatFields.OperateCost,
        (_, current) => current - 1,
        self,
        (env, beneficiary) =>
            runtime.Judge(Orc.Game.Judicators.JudicatorNames.UnitAdjacent, self, beneficiary)
            && runtime.Judge(Orc.Game.Judicators.JudicatorNames.UnitTypeMatch, beneficiary, "infantry")
            && runtime.Judge(Orc.Game.Judicators.JudicatorNames.UnitSide, self, beneficiary)));

    await runtime.RerunAurasAsync(self, ct); // 衔接一轮重跑，使收益立即现算
};
```

### 3.3 减伤预制体（`samples/card-pack-diy/effects/diy.adjacent-cover.mitigation.prefab.json`）

```json
{
  "schemaVersion": 3,
  "root": {
    "id": "diy.adjacent-cover.mitigation",
    "version": 1,
    "oneShot": false,
    "mainTrigger": {
      "id": "t.mitigation",
      "stableKey": "diy·交叉掩护·减伤",
      "kind": "passive",
      "viewType": "Orc.Game.Damage.DamageApplyView",
      "hooks": [],
      "events": [
        {
          "id": "onDamageApply",
          "entry": "HandleAsync",
          "csx": "Func<Orc.Game.Damage.DamageApplyView, Context, CancellationToken, Task> HandleAsync = (view, ctx, ct) =>\n{\n    if (view.Host is not Orc.Cards.Card self)\n    {\n        return Task.CompletedTask;\n    }\n\n    var runtime = Orc.Game.Effects.EffectRuntime.ResolveFor(self);\n    if (runtime is null)\n    {\n        return Task.CompletedTask;\n    }\n\n    if (runtime.Judge(Orc.Game.Judicators.JudicatorNames.UnitAdjacent, self, view.Target)\n        && runtime.Judge(Orc.Game.Judicators.JudicatorNames.UnitTypeMatch, view.Target, \"infantry\")\n        && runtime.Judge(Orc.Game.Judicators.JudicatorNames.UnitSide, self, view.Target))\n    {\n        view.Amount = System.Math.Max(0, view.Amount - 1);\n    }\n\n    return Task.CompletedTask;\n};\n",
          "version": 1
        }
      ],
      "version": 1
    },
    "otherTriggers": [],
    "wrappers": [],
    "injects": [
      { "target": "伤害处理触发器", "band": "Rewrite", "event": "onDamageApply", "priority": 0 }
    ]
  }
}
```

要点：

- `hooks: []` ＋ `injects` ⇒ **纯注入型效果**（E1-36）：主触发器不挂总线，只作注入载体；
- `target` 是**对局级具名触发器**名（`MatchNamedTriggers` 登记）：`伤害处理触发器` / `对战伤害触发器` /
  `效果伤害触发器` / `战斗伤害触发器`；
- `band: "Rewrite"` 解析为 `ActionHandleBands.Rewrite`（处理端最早段）；
- 注入的 handler 生命周期由效果托管（随效果卸载撤销），不需要自己 `Unregister`。

## 4. 触发时序

| 步 | 发生什么 | 符号 |
| --- | --- | --- |
| 1 | 卡装载：两个预制体实例化，`injects` 把减伤 handler 注入 `damage.apply` 的 `Rewrite` 段 | `ApplyFrameworkInjects` → `Effect.InjectByFramework` |
| 2 | `card.load` 广播 → 光环 handler 登记声明并衔接一轮重跑 | `Auras.Register` + `RerunAurasAsync` |
| 3 | 宿主未入场：光环的通用门禁拦截（声明在、收益不生效） | `AuraDeclaration.IsHostActive` |
| 4 | 宿主入场 / 相邻单位位置变化 → 环境事件驱动全域重跑 | `GameEnvironment.HandleUpdateAsync` → `RerunAllCardsAsync` |
| 5 | 受益卡重跑时现收集声明、调谓词（三次 `Judge`）、合成有效值 | `CollectAuras` → `Transform` |
| 6 | 伤害进入处理端：`Rewrite` 段 handler 命中 → `Amount - 1` | `DamagePipeline.Apply` → 默认 handler 扣数值 |

```
card.load ─┬─> aura handler ──> Auras.Register(OperateCost,-1) ──> rerun
           └─> injects ──> damage.apply[Rewrite] = mitigation handler
unit.joined / unit.position.changed ──> rerun ──> collect(auras) ──> opCost -1
damage(dst) ──> effect/combat/battle.damage ──> damage.apply ──> handler: Amount-1 ──> 扣防御
```

## 5. 边界与坑

- **不要用 `BuffAsync` 做“行动花费 -1”**：它是一次性修饰器，单位移开相邻位后仍然生效。
- **不要用 `DeclareAuraAsync` 做“相邻”**：`EffectAuraFilter` 没有相邻维度（`Side/UnitType/ExcludeSelf/...`），
  相邻条件必须自己写谓词（本例）。
- **别在 csx 里写 `GameEnvironment`**：脚本沙箱的屏蔽片段含 `Environment`（防 `System.Environment` 越狱），
  会得到 `[sandbox] 脚本命中屏蔽片段`。正确入口＝`EffectRuntime.AurasOf` / `RerunAurasAsync`。
- **`injects` 目标名必须已登记**：写错＝隔离记录（`注入目标 '...' 未在宿主或对局级登记`），效果静默不生效。
- **减伤是“每次伤害 -1”而不是“防御 +1”**：改 `Amount` 只影响本次结算；改 `Defense` 会改变上限与后续修理语义。
- **可叠加**：两个来源夹住同一单位＝行动费 -2、受伤 -2（光环逐条 `Transform`、handler 逐条改写）。
- **下限**：行动费读取口 `OperateCosts.Effective` 钳 0；伤害量在 csx 里 `Math.Max(0, ...)` 钳 0。
- **隐蔽单位**：光环收集面默认剔除隐蔽受益者（`CollectAuras` 的豁免剔除），这是全局口径而非本卡特例。
