# 信号表

> 纯查表：一个信号＝一个更新字符串（总线上的唯一入口）。列定义：
> **发射时机**（什么时候发）｜**载荷键**（`IReadOnlyDictionary<string, object?>` 的键）｜**引发者来源**（载荷 `Source` 当前由谁写入）｜**典型用法**。
> 代码真源：`GameUpdates`（游戏层 35 条）＋`Updates`（内核 4 条）。行号/签名见 [`_anchors.md`](./_anchors.md) §1。
> **`Source` 语义**：事件引发者，卡对象引用，**恒写、可空**（无引发者＝键存在、值为 `null`）。
> 与视图属性 `TriggerCard`（当前 handler 的触发者、链上最后者胜）分工不同——归因读 `Source`，链内继续传递读/传 `TriggerCard`。

## 1. 回合（5）

| 信号 | 发射时机 | 载荷键 | 引发者来源 | 典型用法 |
| --- | --- | --- | --- | --- |
| `turn.start.before` | 回合开始序列首步（结算/抽牌之前） | Player, TurnNumber, Source | 恒 `null`（回合信号无引发者） | 「回合开始时」前置观察 |
| `turn.start` | 回合开始信号（结算与抽牌随后执行） | Player, TurnNumber, Source | 恒 `null` | 回合级修饰到期（`NextOwnerTurnStart`） |
| `turn.start.after` | 回合开始处理（结算＋抽牌）完成后 | Player, TurnNumber, Source | 恒 `null` | 需要「抽牌后」状态的效果 |
| `turn.end.before` | 回合结束序列首步 | Player, TurnNumber, Source | 恒 `null` | 「回合结束前」收尾 |
| `turn.end` | 回合结束信号（随后切换回合方） | Player, TurnNumber, Source | 恒 `null` | 临时修饰到期（`TurnEnd`） |

## 2. 卡牌（12）

| 信号 | 发射时机 | 载荷键 | 引发者来源 | 典型用法 |
| --- | --- | --- | --- | --- |
| `card.played` | 打出宣告（部署链宣告段 / 指令施放链 `Resolve` 段 priority 0；先于主动效果） | Card, Player, Source | 指令施放链 `Resolve` 段 / 部署链宣告（卡自身注册 ⇒ **被打出卡**） | 「打出时」「使用指令时」（`view.Source` 判归属）；**被反制的指令不发**（`Counter` 的 `Stop` 跳过整个 `Resolve`，视为未成功打出） |
| `card.drawn` | 抽牌动作完成后（随后可接 `card.hand.add`） | Player, Card, Source | 恒 `null`（抽牌服务未透传 source） | 「抽到某牌时」（按 `Card` 判定） |
| `card.stat.changed` | 修饰机制集中触发（有变更才发，单条携带本轮全部变化字段） | Card, ChangedFields, Source | 恒 `null`（修饰机制内部） | 数值变化观察、归零检查 |
| `card.load` | 对局初始化时逐张加载 | Player, Card, Source | 恒 `null` | 加载时点统计/预置 |
| `card.hand.add` | 任意来源进手牌（含抽牌；起手装载不发） | Player, Card, Source | 恒 `null` | 「进手牌时」（与 `card.drawn` 粒度不同） |
| `card.discarded` | 弃置动作完成（移除→销毁→信号） | Card, Player, Source | `DiscardCardAsync(..., source)` 的施动卡；缺省 `null` | 「敌方弃牌时」——`view.Source` 判归属（R9） |
| `card.burned` | 爆牌裁决完成（销毁后；独立信号、不复用弃置） | Card, Player, Source | 恒 `null`（爆牌路径无 source 形参） | 「爆牌时」 |
| `card.died` | 游戏层死亡流程末步（清理就绪后、恰一次） | Card, Killer, Source | 击杀者（`ProcessDeathAsync(..., killer)`；无击杀者 `null`） | 「被消灭时」「本单位消灭敌方时」（`Source`＝击杀者） |
| `card.dying` | 死亡已确认、效果卸载前 | Card, Killer, Source | 恒 `null`（写 `Killer`、未写 `Source`） | 死亡前宿主结算 |
| `card.leaving` | 单位即将离开战场（槽位释放之前） | Card, Reason, Source | 恒 `null` | 离场前快照 |
| `keyword.attack.finished` | 攻击收尾后的词条临时增益到期相位 | Card, Source | 恒 `null` | 临时增益到期清理 |
| `deck.shuffled` | 洗切动作面完成（单副卡组粒度） | Player, Deck, Source | 恒 `null` | 「洗切后」（是否首次由监听者自持） |

## 3. 单位与交战（6）

| 信号 | 发射时机 | 载荷键 | 引发者来源 | 典型用法 |
| --- | --- | --- | --- | --- |
| `unit.joined` | 加入路径单位化完成后（不发 `card.played`） | Unit, Position, Source | 加入链触发者（卡自身注册 ⇒ **被加入单位**） | 「加入支援阵线时」 |
| `unit.deployed` | 部署链单位化完成后（`card.placed` 之后） | Unit, Position, Source | 部署链触发者（卡自身注册 ⇒ **被部署单位**） | 「部署时」（最常用） |
| `unit.position.changed` | 移动执行段（槽位变更后、收尾前） | Unit, OldPosition, NewPosition, Source | 恒 `null`（移动路径未透传） | 守护维护、位移联动 |
| `unit.upgraded` | 升级执行收尾（数值/词条/标记落定后） | Unit, Source | 恒 `null`（升级服务未透传） | 「升为老兵时」 |
| `unit.revealed` | 揭示服务收尾（标记移除＋揭示内容生效后） | Unit, Source | 恒 `null`（揭示服务未透传） | 「被揭示时」 |
| `unit.types.changed` | 类型增补受控入口（实际变更才发） | Unit, AddedType, Source | 恒 `null` | 「获得某类型时」 |

## 4. 伤害、行动与反制（6）

| 信号 | 发射时机 | 载荷键 | 引发者来源 | 典型用法 |
| --- | --- | --- | --- | --- |
| `card.damaged` | 伤害结算后、实际扣减 > 0（单位/HQ 各自路径） | Card, Amount, Source | 恒 `null`（伤害路径未写 Source） | 「受伤时」 |
| `unit.acted` | 攻击/移动外层收尾成功后（各自恰一次） | Unit, Source | 恒 `null` | 「行动后」 |
| `unit.damage.dealt` | 单位实际造成伤害后（来源侧，实际变化量 > 0） | Unit, Card, Amount, Source | 恒 `null`（写 `Unit`＝施动方、未写 Source） | 「本单位造成伤害时」——读 `Unit` 即施动方 |
| `unit.combat.survived` | 对战结算收尾（参战且未阵亡者各一次） | Unit, Source | 恒 `null` | 「战斗存活后」 |
| `counter.triggered` | 反制**激活**分支（取消分支不发） | Card, Player, Source | 使用反制触发者（卡自身注册 ⇒ **反制卡**） | 「反制触发时」 |
| `counter.disarmed` | **己方回合开始**时窗口到期自动解除（注销 handler → 置未激活 → 清实扣额，不退点、不消耗；解除**之后**发射） | Card, Player, Reason, Source | 恒为**反制卡自身**（与 `counter.triggered` 同口径） | 「反制武装到期时」（`Reason` 恒 `"turn-start"`） |

## 6. 内核更新（4）

> 内核信号**没有 `Source` 键**（不经 `GameUpdates` 发射助手）：它们只承载对象引用。

| 信号 | 发射时机 | 载荷键 | 引发者来源 | 典型用法 |
| --- | --- | --- | --- | --- |
| `card.placed` | 部署链/加入链单位化成功后、完成信号之前 | Card | 无 `Source` 键（内核） | 放置驱动装载（策略 1 效果） |
| `card.destroyed` | 引擎销毁（`DestroyCard`；装载链清理驱动） | Card | 无 `Source` 键 | 引擎级清理兜底（≠ `card.died`） |
| `card.data` | 卡牌数据变更 | Card | 无 `Source` 键 | 数据组件变更观察 |
| `effect.removed` | 效果实际移除命中（恰一次；回滚/幂等不发） | Card, Effect | 无 `Source` 键 | 效果卸载清理收敛 |

## 7. 口径与缺口

- **32 vs 35**：`GameHooksJson.SignalMetadata` 只导出 32 条（不含 `card.dying` / `card.leaving` / `keyword.attack.finished`）；`GameUpdates` 与 `GameHooks.Signals` 实为 **35** 条。订阅时以本表为准。
- **`Source` 何时非空**：目前只有 7 类信号会写非空 `Source`——`card.played`、`card.discarded`、`card.died`、`unit.joined`、`unit.deployed`、`counter.triggered`、`counter.disarmed`（其中 `card.discarded` 取决于调用方是否传 `source`）。其余信号的 `source` 形参已就位但下游服务未接线，见 [缺口表](./缺口表.md) G-04。
- **归因三选一**：`Source`（事件引发者）｜载荷里已有的对象键（如 `unit.damage.dealt.Unit`＝施动方）｜`TriggerCard`（当前 handler 的触发者）。不要用 `TriggerCard` 代替 `Source` 做「敌方所致」判定。
- **伤害三端不是总线信号**：`combat.damage` / `effect.damage` / `battle.damage` / `damage.apply` 是 **具名触发器**（`CommandManager.DamagePipeline`），不是 `GameUpdates` 信号——不订阅总线、不写 `Source` 载荷；改写用 `Register(..., band)`（见 [api速查](./api速查.md) §1.1）。它们产生的可观察信号仍是表内的 `unit.damage.dealt` / `card.damaged` / `card.died`。
