# 缺口表（能力边界汇总）

> 纯查表：本表是 08 章「能力边界」的代码侧汇总，**编号与 08 章逐条一致**（G-01…G-11）。
> 列定义：**现象**（作者会遇到什么）｜**层级**（四级，互斥）｜**现状替代**（不改引擎怎么绕）｜**需改哪里**（最小改动点）｜**关联示例**。
> 代码真源与符号定位见 [`_anchors.md`](./_anchors.md)；信号 `Source` 现状见 [`信号表.md`](./信号表.md) §7。

## 层级定义（互斥，只选一个）

| 层级 | 含义 | 判据 |
| --- | --- | --- |
| **内核缺** | 引擎内核没有该能力，游戏层无法补 | 需要的符号在内核不存在 |
| **游戏层未接线** | 内核有能力，游戏层未暴露/未接上 | 符号存在但为 `internal`、未注册或未落到流程 |
| **规则缺失** | 代码能做，但对局规则没有定义该时机/口径 | 有信号/动作，但语义未定 |
| **部分可覆盖** | 可逼近，但与真实语义有已知差异 | 替代路径可跑，差异可列出 |

## 使用规则

- 本表每条**必须**给「现状替代」；写不出替代的，把「需改哪里」写成最小改动点，不得只写「不支持」。
- 层级只能选一个；同一现象跨两层时，拆成两条各自表述。
- 编号与 [08 章](../08-能力边界.md) 同名同义；改一处必须改另一处。
- 已解决项保留行并标「已解决」，不删除（避免正文/示例仍把它当缺口）。
