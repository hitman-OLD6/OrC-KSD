## Language

**动作（Action）**：
上位词——一次"改变对局状态"的完整意图单位：加入战场、卡牌移动、攻击、指令施放、伤害结算、死亡、抽牌、加入手牌。
_避免_: 行动（那是资源与次数层）、操作、operation（词条程序的 op）

**行动（Operate）**：
**攻击与移动这两个指挥操作的统称**；也是资源与次数的计量单位（行动费、行动位 `CanMove`/`CanAttack`、`unit.acted`）。**不设显式声明与实体**，不是一个动作。
_避免_: 单位行动（无对应实体）、operate 之外的新词

**动作实体（Action Entity）**：
一个动作在代码中的可寻址承载——动作标识、视图类型、触发器序列、结果对象。
_避免_: 动作定义、ActionDefinition（数据侧说法）

**触发端（Trigger End）**：
动作的**施动者视角**触发器：能否发起、代价几何、发起时的改写与拦截。
_注意_: 与"触发器（Trigger）"这一机制不是同义词；触发端是一个触发器，但"触发"在此指"动作被发起"。
_避免_: 发起触发器、前置、pre

**处理端（Handle End）**：
动作的**承受者视角**触发器：结果改写、状态落地。
_避免_: 处理器（那是 handler）、执行器、apply

**唯一落地口**：
不变量——某动作的状态变更只能由该动作处理端的默认 handler 执行，其余路径一律收敛或禁止。
_避免_: 单一写入点、门户（"门户"在根表另有所指）

**元效果（Meta Effect）**：
对某次动作的**实施过程**进行干预的效果：改代价、改目标、改数值、阻止、重定向、复制、追加副作用。反制是其中"阻止"的特例。
_避免_: 效果的效果、meta、超级效果

**三段接缝**：
元效果的三个挂载位置——**发起前**（触发端）、**宣告后**（触发端末/处理端之前）、**落地前**（处理端内）；落地后沿用总线信号。
_避免_: 检查位、拦截点（笼统）

**底层逻辑集（Foundation Logic Set）**：
一组动作实体的定义与默认 handler 的集合——规则骨架的载体，**定义权归插件**（`orc.foundation.actions`）。
_避免_: 内置逻辑、核心规则、默认实现集

**动作服务面（Action Service Surface）**：
底层逻辑集的 handler 访问对局的**受控写面**：具名操作（扣费/移动落地/清行动位…），不交出管理器实例。
_避免_: 对局上下文、服务定位器、God object

**入口分支（Entry Branch）**：
一个语义入口的完整编排单元：自身前置 → 调用底层动作 → 自身收尾。分支在入口、结果在底层。
_避免_: 包装、前置

## Ambiguities to Clarify

**「触发」的三重含义**：
① 机制名 `Trigger`；② 动作被发起（本表"触发端"）；③ 效果被事件命中（"触发一次效果"）。同一句中不得混用。
