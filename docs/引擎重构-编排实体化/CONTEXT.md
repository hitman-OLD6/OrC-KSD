# CONTEXT — 编排实体化

本文件只登记**本次重构引入或重新定义**的术语。未列入者以仓库根 `CONTEXT.md` 为准；
根 `CONTEXT.md` 中与本文件冲突的条目，以本文件的仲裁结果为准（见 §2）。

## 1. Language

**实体（Entity）**：
运行时对象的最小单位，具名、可终结、可安全引用。分四类：**引擎实体**、**卡牌实体**、**组件实体**、**handler 实体**。
与 `Orc.Core.Entity` 基类同源——"实体"是类型，不是某一个具体类。
_Avoid_: 对象、实例（与"预制体实例"混淆）

**组件（Component）**：
可被其它实体组合的实体；拥有自己的成员 handler 集、可见性、生命周期与初始化触发器。
**自托管**：组件自己声明挂在哪、自己初始化、自己注销，宿主不参与装配。
（与卡数据的**数据组件**不同层，见下）
_Avoid_: 插件、模块、mixin、附加物

**数据组件（Data Component）**：
卡数据 `components` 数组里的条目（`factionCost`/`battleStats`/`tagData`/`keywords`/`typeCategory`）。
**是数据，不是实体**：不挂载、不进成员表、无生命周期。其中 `typeCategory` 是组件实体的绑定键。
_Avoid_: 组件、部件、Section

**装配时点（active-when）**：
组件声明自己何时被装配：`loaded`（宿主加载即装配，供"在手中生效"的效果）／`placed`（宿主入场才装配，默认）。
_Avoid_: 装载时机、hook、生命周期钩子

**复装（Remount）**：
宿主重新入场时**重建**组件实例（私有字段复位），不复用旧实例。
_Avoid_: 重新装载、重入、恢复


**效果（Effect）**：
**一个效果组件的成员 handler 集**——描述"这张卡在这个时机会做什么"。效果**不是实体**；
实体是承载它的组件。
_Avoid_: 效果类、效果实例、Effect

**预制体（Prefab）**：
实体的模板，等价于 OOP 的**类**；纯文本，描述成员 handler、继承关系与可见性。
_Avoid_: 配置、模板文件、效果文件

**成员 handler**：
预制体声明的一项成员，指向一个 handler 资产（或内联逻辑）。
它**不是每实例对象**——"调用成员"＝调用全局注册的那份 handler，并把 owner 作为第一个参数自动回填。
等价于 OOP 的实例方法。
_Avoid_: 注册项、事件、entry、成员对象

**懒注册（Lazy Registration）**：
handler 资产在**首次被某个待实例化的预制体引用时**注册一次，之后全局复用。
_Avoid_: 预加载、按需编译、初始化注册

**owner**：
成员 handler 的宿主实体，等价于 C# 的 `this` / Python 的 `self`；调用时由框架作为第一个参数自动回填，
并通过视图的内建 `Owner` 字段暴露。**不是**数据面投影出来的字段。
组件成员的 owner 是**组件实体**；要访问卡牌需经 `owner.host`。
_Avoid_: self、this、宿主（"宿主"另指挂载宿主）

**宿主（Host）**：
组件实体所附着的实体（卡牌／HQ）。组件实例化时由框架填入引用；经 `owner.host` 到达。
_Avoid_: owner、父实体、挂载点

**可组合实体（Composable）**：
允许携带组件实体的实体（至少：卡牌、HQ）。"可组合"是实体的声明能力，不是某个具体类的特权。
_Avoid_: 卡牌专属、容器

**公共变量（Public Variable）**：
由触发器**上下文视图**声明的字段，从数据面投影，跨步骤／跨成员流通。可写需显式声明。
_Avoid_: 全局变量、共享状态、Context.Data

**私有变量（Private Variable）**：
由**实体预制体**声明的字段，随实体实例存在，只经 `owner.<field>` 访问；不进数据面。
计数、开关、"上次目标"这类跨执行状态属于此层。
_Avoid_: 成员字段、实例状态、缓存



**触发器（Trigger）**：
**带嵌入逻辑的 handler**——嵌入逻辑固定为「上下文视图 + 合法性检验 + 按顺序调用挂载的 handler」。
可被挂载到其它触发器上。原"主动触发器"即此物。
_Avoid_: 主动触发器、流程触发器

**handler**：
**无嵌入逻辑的可执行节点**：只有"被执行"这一件事，数据由宿主传入、不自己绑定视图。原"被动触发器"即此物。
_Avoid_: 被动触发器、回调、监听器

**挂载（Mount）**：
**设计端的编排通道**：把 handler／触发器附着到宿主触发器上，表达"这个流程里有哪些步骤、按什么次序"。
挂载点由宿主的**可见性**约束，执行序由声明序决定（跨预制体时按装载序）；挂载**不表达**"替换宿主核心逻辑"。
_Avoid_: 注入、订阅、注册、绑定

**信号（Signal）**：
**引擎实体的成员触发器**，代表一个发生过的时机（`card.load`、`card.destroyed`、`unit.deployed`…）。
调用它＝广播；"订阅"＝挂载到它上面——订阅不是独立通道。
_Avoid_: hook、事件、总线、Emit 目标

**运行时注册（Runtime Registration）**：
运行期向引擎注册新触发器，使其在全局范围内可被寻址与挂载（替代"必须走引用查询"）。
注册是显式动作；引用未注册触发器＝明确失败。
_Avoid_: 动态挂载、热注册、插件注入

**注销兜底（Disposal Fallback）**：
框架自动为每个组件挂到 `engine.card-destroyed` 的注销边，位次固定为该组件所有已声明挂载之后。
隐式成立，但审查面必须标注来源为 `framework:disposal`。
_Avoid_: disposing 触发器、销毁钩子、OnUnmount



**包装（Wrap）**：
**元效果端的修改通道**：在别人的执行外围改写或拦截（before / after / replace + 具名接缝）。
由反制、光环、减伤这类"修改别人结算"的效果使用；包装**不引入**新的编排步骤。
`before` 与 `after` 均按声明序正序（FIFO）；`replace` 为最后声明者生效。
_Avoid_: 挂载、注入、相位

**自有边位次（own-edge-position）**：
成员声明自己的自有边排在边集合的 `first`（流程型：核心先跑）还是 `last`（管道型：落地最后跑）。
默认 `first`。
_Avoid_: 优先级、band

**设计端（Design side）**：
编写卡牌／流程编排的人。其唯一通道是挂载。

**元效果端（Meta-effect side）**：
编写"修改别人行为"的效果的人。其唯一通道是包装。


**可见性（Visibility）**：
成员 handler 的**能力位标志**（正交组合）：`可被调用` / `可作宿主（挂载 handler）` / `可被挂载`。
默认全关；子实体只能收紧不能放宽。能力范围由所属实体类型决定（引擎实体＝全对局，卡牌实体＝本卡实例）。
_Avoid_: 访问修饰符、public/private、角色

**成员寻址**：
挂载声明定位目标的方式：`作用域#成员名`（如 `engine#damage-apply`、`engine#card.destroyed`、`host#played`、`self#on-damaged`）。
作用域 ∈ {`engine`（引擎实体）, `host`（宿主实体）, `self`（组件自身）}；**第一个 `#` 之后整体是成员名**，
成员名允许含 `.`，不做分隔符替换。不使用任何显示名。
_Avoid_: 触发器名、稳定键、路径、`实体.成员`


**初始化触发器（Init Trigger）**：
实体基类内置的触发器，实例化后由**框架**调用；按预制体的成员声明与挂载声明完成装配。
不可覆写、不承载业务逻辑——漏挂成员在设计上不可能发生。
_Avoid_: 装载钩子、OnMount、构造函数

**继承（Extends）**：
子预制体对父预制体的**全继承**：成员清单、视图声明、可见性、初始化触发器实现一并获得。
_Avoid_: 组合、mixin

**覆写（Override）**：
子预制体把父的某个成员换成另一个 handler 资产——**整段替换**，不提供 super 调用。
"在父逻辑前后加一段"用相位（phase）表达；"在中间插入"靠父预制体拆成员。
_Avoid_: 重载、钩子、扩展点

**引擎实体（Engine Entity）**：
承载全局流程的实体，**对局级单例**。原"引擎初始化注册的全局触发器"是其成员 handler；
OOP 的"静态方法"在此被解释为引擎实体的成员。成员寻址根固定为 `engine`。
_Avoid_: 全局触发器、底层触发器、对局实体

**ctxViewer**：
执行期视图包装器：按成员声明的视图字段从数据面投影出视图对象，并**回填 owner 引用**。
_Avoid_: 视图绑定器、代理工厂

**视图（View）**：
触发器内声明的一份字段清单（文本），描述"本触发器要读／写执行上下文的哪些键"；由 ctxViewer 按名投影成只读/可写成员。
_Avoid_: ContextView、代理类、DTO

**承载视图（View Carrier）**：
承接全部视图声明的**唯一**通用运行时类型（实现动态成员读写）：csx 以 `Func<dynamic, Context, CancellationToken, Task>`
为入口签名，`view.<Name>` 按名投影到**数据面**。「不为每个数据形状新增 C# 类」正是靠它成立。
私有字段不经它访问（唯一通道是 `owner.<Name>`）。
_Avoid_: View 基类、代理类型、生成类型


**封闭类型集**：
视图字段可用的全部类型：实体引用 / 数字 / 字符串 / 布尔 / 以上四种的数组。**不支持嵌套结构**——
需要复杂计算或复合结构的场景退回 csx。
_Avoid_: 类型系统、schema 类型

**数据面（Data Plane）**：
一次执行链上流通的键值集合，由宿主触发器持有；视图是它的投影，写回也落在这里。
_Avoid_: Context.Data、字典、参数包

**投影（Project）**：
按视图字段声明从数据面取值的动作；字段名即键名，取值即绑定。
_Avoid_: 绑定、映射、反射赋值

**targeter**：
**特殊判定器**：除判定契约外独有**提交通道**，必须由前端显式处理。
_Avoid_: 选择器、selector（selector 只是其产出物）

**提交通道（Submit Channel）**：
targeter 与前端之间的显式往返：引擎产出待决请求，前端提交裁定；引擎不代选。
_Avoid_: 回调、返回值

**前端（Frontend）**：
能对 targeter 提交裁定的实现——人类 UI、MCP 客户端、AI 都是它的实现形态。
**不存在"无头例外"**：沙盒只是把前端换成了 MCP/AI，引擎侧零特判。
_Avoid_: UI 层、客户端、无头模式

**裁定（Adjudication）**：
引擎无法自行决定、必须由外部意志给出的选择动作；与"确定性求值"（候选集即答案）相对。
_Avoid_: 选择、挑选、决策

**随机选择器（random selector）**：
由引擎随机服务（对局种子可复现）裁决的取样，**不产生 targeter**。
生产对局禁用；仅简单 AI／测试场景可开启。
_Avoid_: 随机 targeter



## 2. Ambiguities to Clarify

| 术语 | 冲突 | 仲裁 |
| --- | --- | --- |
| 触发器 | 根 `CONTEXT.md` §99："纯编排节点，不承载业务逻辑" | **已仲裁**：新语义为"带嵌入逻辑（视图／合法性／顺序调用）的 handler"，覆盖旧定义 |
| handler | 根 `CONTEXT.md` §64："监听 handler（自写）"；代码里指触发器内注册项 | **已仲裁**：新语义为"全局懒注册的可执行节点，owner 为自动回填的第一个参数" |
| 实体 | `Orc.Core.Entity` 仅覆盖卡牌／单位／玩家 | **已扩展**：四类实体（引擎／卡牌／组件／handler），仍是同一基类 |
| 预制体 | 现有三层 `EffectPrefab`／`TriggerPrefab`／`EventPrefab` | **已升级**："类"；旧三层结构随 R8 批次 5 退役 |
| 效果 | 现有 `Effect` 类（触发器 + 注入 + 装载链） | **已重定义**：效果＝组件实体的成员 handler 集，不是实体 |
| owner | 借用 OOP 的 this | **已消歧**：`owner` 恒指 handler 所属实体；组件的宿主用 `host`（不叫 `owner.owner`） |
