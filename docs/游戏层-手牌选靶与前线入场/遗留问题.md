## 二、遗留问题（按优先级）

### P0 — 影响实际功能，建议 push 后立刻处理

1. **资产层 csx / 效果模板仍引用 `UnitStateData.Position`**
   - 现象：`BulwarkKeywordTests.抢修_己方回合开始_未移动未攻击则回满` 报
     `词条 '抢修' 的数据壳效果 'keyword.repair' 实例化失败（compile）：“UnitStateData”未包含“Position”的定义`
   - 已定位文件（含 `bin/` 产物，需改源文件）：
     - `src/Orc.Game/EffectParsing/Templates/position_basic.tpl.json`
     - `src/Orc.Game/Cards/KeywordPrefabs/keyword.mobilize.accrual.csx.prefab.json`
     - 同类 `keyword.*.prefab.json` 内嵌 csx
   - 影响：所有挂 `keyword.*` 的词条效果装载 fail-fast（授予整体回滚），对应测试成片失败。
   - 修法：把脚本里的位置读法改为 `state.Line`（或经 `EffectRuntime` 提供的位置读取面），再全量重跑。

2. **`EnableDefaultItems` 之外的资产副本未同步**
   - `src/*/bin/Debug/net8.0/...` 下的同名 json 是构建产物，不需要手改，但需确认源文件改动后重新构建才会被复制。

### P1 — 测试收敛（159 红）

3. **测试内直接索引越界**（约 40 处）
   - 形态：`front[2]`、`support[3]`、`line[i]`（`BattleLine` 索引器返回元素，线内元素不足即越界）。
   - 修法按意图二选一：
     - 作为**位置**使用 ⇒ `line.GetInsertionGaps()[n]`
     - 作为**元素**使用 ⇒ `line.Members[n]`（或保持 `line[n]`，但要先确认元素存在）
   - 典型文件：`AuraSystemTests`、`CovertMechanismTests`、`JudicatorCombatLegalityTests`、`CommandSystemTests`、`PlayChainUnitTests`。

4. **`Assert.Same` 载荷比较失败**（约 15 处）
   - 形态：`Assert.Same(hq, line[0].Occupant)` → 已去掉 `.Occupant`，但仍有 `Assert.Same(oldSlot, payload[...])`。
   - 修法：载荷已是 `BoardPosition`，比较 `((BoardPosition)payload[GameUpdates.PayloadOldPosition]!).Line`。

5. **沙盒 `slot-out-of-range`**（5 处，`SandboxPrimitiveTests`）
   - 沙盒入参 `slotIndex` 现在是**插入序号**（0..N），不是旧槽号 0..4；测试传的旧号需换算。

6. **`PrepareOnSupportAsync` / `PrepareOnFrontAsync` 的 index 已钳制**
   - 为避免抛错，越界 index 被钳到最后一个插入点；这会让"放在第 3 位"的测试实际落在末尾。
   - 属临时手段，需改为"按需要的元素数先铺底再插入"，或明确测试只依赖"存在性"而非精确序号。

### P2 — 命名与清理

7. **`SelectorNames.Slot` 改名后的一致性复核**
   - 已改：`SelectorNames` / `SelectorTemplates` / `TargeterBridgeAdapter.KindOf`（`"slot"` → `"deployGap"`）。
   - 待复核：`Orc.Ai` 的 `AiPilot` 是否还有按字面 `"slot"` 分支；`samples/Orc.Game.Sample/DemoTargeterBridge.cs` 的 `Slot` 类型判别已替换为 `FormationGap`。
   - 对外协议串已从 `slot` 变为 `deployGap`，前端/桥接若按字面匹配需同步。

8. **`PlayManager.DeploymentLines` 未完全退场**
   - 现状：`DeploymentCandidates` 优先走判定器提供器，`DeploymentLines` 作为兜底保留（独立构造场景）。
   - 目标：判定器为唯一真源后删除兜底（否则仍存在"第二真源"）。

9. **测试侧 `TestPositionCompat`**
   - `tests/Orc.Game.Tests/TestPositionCompat.cs` 为测试专用适配（`Card.IsEmpty() => false`、`FormationGap.IsEmpty()`），属迁移过渡物，测试收敛后应删除。

10. **`BattleLine.Clear()` / `FormationGap.Place()` 缺失**
    - 旧测试里有"清空线 / 在某位置放占位物"的写法，已被注释或替换；若后续测试需要，应提供 `TryRemove` 循环或测试侧辅助，不恢复生产 API。
