### S14: `version.set` 同步同 sidecar 宿主与内含资产（F2）
- Status: Done
- Target：`src/Orc.Packages/Editing/AssetEditorSession.cs`（`SetVersion`／`ApplyVersion`／`AutoNext`／`_pinned`／`CommitPrefab`／`ComputePromotedVersions`）、`tests/Orc.Packages.Tests/AssetEditorTests.cs`
- Approach（I12 已裁定：组内最大版本为基准 ＋ 组粒度 pinned）：
  - **组定义**（唯一口径，供本步全部子项复用）：「组」＝`_assets` 中 `SidecarRelative` 相同的全部条目（宿主 ＋ 全部内含），排序按 `(Kind, Id)` 保确定性。
  - **手写基准**：`SetVersion(kind, id, text)` 的候选版本须**严格大于 `max(组内当前版本)`**（`AssetVersion` 规范形比较，不改比较/派生语义）。拒绝时抛 `VersionNotIncreasing`，消息指名「组内最大 `<max>`（来自 `{kind}:{id}`）——请使用 ≥ 其严格递增值」。`max` 的来源条目在并列最大时取 `(Kind, Id)` 最小者，保证消息稳定。
  - **自动递增**（`version = null`）：`current` 取组内 `max`；
    - 「组内**每条都有 baseline**（`_initialAssets` 命中）且**都等于其 baseline**」且「组内版本一致」⇒ 走 `TestVersionOf`（追加测试段）；
    - 任一条不满足（含历史分裂、本会话新建混合）⇒ 走 `Next`（尾段 +1）。
  - **pinned 改按组**：`_pinned` 由 `HashSet<EditorAssetKey>` 改为 `HashSet<string>`（`sidecarRelative`，`StringComparer.Ordinal`）。
    - **登记点只有两处**：`SetVersion`（显式设定）与 `CreateAsset`（新建即 `1.0.0`）——都 pin 整组；
    - **`CommitPrefab`／`CommitCard` 只消费、不登记**（提交不是「显式设定版本」；若提交也 pin，则第二次提交永远不再 +1，版本会停住）；
    - **消费点只有 `AutoNext`**：按组查询并清除（一次提交只消费一次）；`DeleteAsset` 在组删空时清除该组 pinned，组未删空则保留。
  - **`ApplyVersion` 改为组改写**：组内全部条目统一写 `Version = 目标版本`、`Guid = DeriveGuid(kind, id, 目标版本)`；sidecar 的 `assets[]` 以同规则整份重写（复用 `WriteSidecar`），`_assets` 逐条替换。
  - **`CommitPrefab` 的 `previousVersion` 改为组内 `max`**（替换 `existing?.Version ?? host?.Version`），并沿用 `AutoNext` 的组语义（只消费 pinned）；写回时组内全部条目与宿主同版本（现有 `:678-681` 的广播逻辑保留，基准换成组 max）。
  - **`ComputePromotedVersions` 补分裂自愈**：
    - 组内版本**不一致**（历史分裂）⇒ 无论是否改动，组内所有条目统一为 `PromoteVersion(max)`；
    - 组内版本一致且全部未变 ⇒ 保持原版本不动（配合 S17 的窄写，未改动 sidecar 字节不变）；
    - 组内版本一致且有改动 ⇒ 走现有规则（`PromoteVersion(宿主)` 为组版本）。
  - `PreviewLocks`／`BuildTestLock`／`LockEntry` 已按 `entry.Metadata.Version` 取值，组同步后三处自然一致。
- Acceptance:
  - [ ] 宿主 `1.0.0` ＋ 内含 `1.0.0`，`SetVersion(Effect, host, "1.1.0")` ⇒ 宿主与内含均 `1.1.0`，且 `AssetGuid` 各自重算
  - [ ] 对含 **2 个**内含条目的 prefab 同样全部同步（`asset_list` 三条均为 `1.1.0`）
  - [ ] 反向用例：`SetVersion(Trigger, embedded, "1.1.0")` 把宿主也推到 `1.1.0`（F2「对任一资产」字面）
  - [ ] 历史分裂（宿主 `1.0.0` ＋ 内含 `1.2.0`）：`SetVersion(host, "1.0.1")` ⇒ `VersionNotIncreasing`，消息含「组内最大 1.2.0」与该条目；改为 `"1.3.0"` ⇒ 全组 `1.3.0`
  - [ ] 历史分裂 + 不做任何改动直接 `promote` ⇒ 转正后组内版本一致（`promoted = PromoteVersion(max)`）

  - [ ] `version.set` 内含 → `commit` 宿主：宿主不越过内含（两边同为 pinned 后的版本）
