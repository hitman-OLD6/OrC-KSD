# 「跨越海洋」卡包使用指南

这份指南带你把这个卡包放进游戏，并在对局里用上七张卡：三辆 LVT 两栖载具、四张登陆指令。

---

## 一、这个卡包里有什么

| 卡 | 类型 | 费用 | 在牌桌上的效果 |
|---|---|---|---|
| **LVT-2** | 载具 2/3 | 2（行动 1） | 与它相邻的友方步兵 +2 攻击力、-1 行动花费。 |
| **LVT-4** | 载具 4/5，闪击 | 4（行动 2） | 它移到前线时，所有友方步兵 +2 攻击力、-1 行动花费（永久）。 |
| **LVT-1** | 载具 3/4，闪击 | 3（行动 1） | 它移到前线时，从手里随机带一张费用 ≤2 的步兵一起进前线。 |
| **滩头补给** | 指令 | 2 | 你每有 1 个友方步兵，就随机让 1 个友方单位获得 +1/+1。 |
| **迅速登陆** | 指令 | 2 | 本回合内，你的单位部署或加入时，随机对一个敌方目标造成 1 点伤害。 |
| **两栖登陆** | 指令 | 3 | 若前线有你方单位：把手里所有费用 ≤2 的单位放进前线，并把它们压制到回合结束。 |
| **大规模登陆** | 指令 | 5 | 随机把 4 个费用 ≤3 的美国步兵放进你的支援阵线。 |

另外附带两张美国步兵作为卡池补充（也是「大规模登陆」的来源）：

- **美国步枪兵** —— 0 费 1/2
- **第554步兵团** —— 1 费 1/2

小提示：LVT-2 是「站桩光环」，适合放在两个步兵中间；LVT-4/LVT-1 是「推进型」，越早移到前线收益越大。

## 二、把卡包放进游戏

### 1. `packs` 文件夹在哪里

`packs` 是游戏读取卡包的固定文件夹，位置规则是：**与游戏启动文件（`.exe` 或启动器）在同一层**。

以 Windows 为例，如果游戏装在 `D:\Games\OrcKsd`，那么：

```
D:\Games\OrcKsd\
├── OrcKsd.exe          ← 游戏启动文件
└── packs\              ← 卡包文件夹（没有就自己新建，名字必须是 packs）
```

放好之后，完整路径应该是：

```
D:\Games\OrcKsd\packs\card-pack-across-the-pacific\manifest.json
```

三种常见情况：

- **游戏目录里已经有 `packs`**：直接用它，不要新建第二个。
- **游戏目录里没有 `packs`**：在游戏启动文件旁边新建一个文件夹，命名为 `packs`（全小写）。
- **游戏设置里能设置「卡包目录 / 模组目录」**：以设置里显示的那个路径为准，把卡包放进那里。

如果找不到游戏安装位置：右键点击桌面上的游戏快捷方式 →「打开文件所在位置」，就会跳到启动文件所在的文件夹。

### 2. 复制卡包

1. 解压本压缩包，得到 `card-pack-across-the-pacific` 文件夹（里面直接有 `manifest.json`）。
2. 复制**整个 `card-pack-across-the-pacific` 文件夹**（不是只复制里面的文件）。
3. 粘贴到上面的 `packs` 文件夹里。

复制完成后应该长这样：

```
packs/
└── card-pack-across-the-pacific/
    ├── manifest.json
    ├── lock.formal.json
    ├── lock.test.json
    ├── effects/
    └── cards/
```

### 3. 放好后的检查

打开 `packs\card-pack-across-the-pacific`，**第一眼就应该能看到 `manifest.json`**。

- 如果打开后看到的是另一个同名文件夹，说明多套了一层，游戏会去 `packs\card-pack-across-the-pacific\card-pack-across-the-pacific\manifest.json` 找，结果找不到；
- 修正方法：把里面那一层文件夹直接移到 `packs` 下，保证 `manifest.json` 只隔一层。

其他要点：

- 文件夹名可以改，但 `manifest.json` 里的 `id`（`orc.across-the-pacific`）不要改；改了就当成另一个卡包。
- **不要删除 `lock.formal.json` 与 `lock.test.json`**：这两个文件记录本包资产的身份证（GUID），删了整包不会装载。
- 每个 `.card.json` / `.prefab.json` 旁边都有一个同名 `.meta.json`，是资产登记表，一起保留。

## 三、让游戏读取卡包

1. 完全关闭游戏，再重新打开（卡包只在启动时发现）。
2. 新建一局对局（已经开着的对局不会出现新卡）。
3. 打开卡牌图鉴或组卡页面，搜索「LVT-2」「滩头补给」等卡名。
4. 把卡加入卡组，开始对局。

---

## 四、对局里怎么用

### LVT-2（相邻光环）

1. 把它放在支援线，左右各摆一个步兵，两个步兵立刻变成 +2 攻击、行动费用 -1。
2. 它自己不是步兵，不会被自己的光环加成。
3. 它被消灭后，光环立刻消失。

### LVT-4（推进增援）

1. 它带「闪击」，出场即可行动。
2. 把 LVT-4 移到前线的那一刻，你**所有**友方步兵永久 +2 攻击、-1 行动花费（不管在前线还是后排）。
3. 在前线内部挪格子不会再触发；从支援线移上去才算。

### LVT-1（带人上岸）

1. 同样带「闪击」。
2. 手里先留一张费用 ≤2 的步兵；把 LVT-1 移到前线时，会自动带走其中一张，一起落到前线。
3. 前线没有空位时，这次带人不会发生（LVT-1 自己仍然会移动）。

### 滩头补给

1. 数一下你场上现在有几个步兵，有几个就触发几次。
2. 每次随机挑一个**友方单位**（可能是同一个单位被挑中多次）+1/+1，是永久加成。
3. 场上没有友方单位时，打出它没有效果。

### 迅速登陆

1. 打出后，本回合内你的单位每次「部署」或「加入」时，都会随机打敌方 1 点伤害（可能打在敌方单位上，也可能打总部）。
2. 效果只持续到本回合结束，不会带到下个回合。
3. 对手的单位进场不会触发。

### 两栖登陆

1. 需要你**前线已经有单位**才能生效；前线空着时打出没有效果。
2. 生效后，手里所有费用 ≤2 的单位会一起进前线，并被压制（本回合不能攻击/移动）。
3. 前线格子不够时，能放几个放几个。

### 大规模登陆

1. 打出后，随机把 4 个「美国 + 步兵 + 费用 ≤3」的单位放进你的支援阵线。
2. 同名卡可以重复出现；支援阵线挤满时会少放。

## 五、看不到卡或效果不生效

1. **图鉴里没有这些卡**：确认卡包在 `packs\card-pack-across-the-pacific\`、`manifest.json` 只隔一层、游戏已完全关闭后重开、并新建了对局。
2. **卡出现了但技能没反应**：
   - LVT 系列的光环/推进要靠「战场位置」判断：先确认单位真的在前线（不是支援线）；
   - 两栖登陆要求前线已有你方单位；
   - 滩头补给要求场上已有友方单位。
3. **报错「卡池装配失败」或看不到包**：检查 `lock.formal.json`、`lock.test.json` 与各 `.meta.json` 是否齐全；这三个是装载必需项。
4. **同一张卡出现数值不对**：以卡面为准核对 `cards/*.card.json` 里的 `kredits` / `attack` / `defense` / `operationCost`。

## 六、自己改一改

### 改卡名和数值（安全做法）

用记事本打开 `cards` 文件夹里的卡文件：

- `"name"` 后面引号里的字是卡名；
- `"kredits"` 是部署费用、`"operationCost"` 是行动费用、`"attack"` / `"defense"` 是攻防；
- 只改引号里的文字或数字，不要删除大括号、逗号。

改完保存、重开游戏、新建对局。

### 改完卡后必须重建资产登记（重要）

本包的资产 GUID 是**按身份算出来的**（包 GUID + 类型 + 卡 id + 版本）。手改内容不改版本时，GUID 不变、可以直接用；但一旦新增/删除卡、或改 `id`/版本，就必须重建 `manifest.json`、`.meta.json` 与 lock，否则整包会被判非法。

重建方法（需要 Python 3.10+）：

```
cd card-pack-across-the-pacific
python _tools/build.py
```

脚本会按 `_tools/build.py` 里的卡表重写 `cards/`、`effects/`、`manifest.json` 与两个 lock。
注意：它按脚本内的卡表生成，直接手改过的卡文件会被覆盖——要长期保留的改动请改脚本里的卡表。

### 做一张新卡

1. 复制一张现有卡文件，改文件名；
2. 把 `"id"` 改成新名字（不能和现有卡重复）；
3. 改 `"name"`、数值与 `"keywords"`；
4. 补一个同名 `.meta.json`（GUID 用上面的重建脚本生成，别手填）；
5. 重开游戏、新建对局。

## 七、已知的小限制

- LVT-1 的「选择手中一张」目前由系统随机挑一张（游戏还没有手牌选择界面）。
- 「加入前线」在引擎里分两步完成（先进支援线相邻空位，再推进到前线），最终位置与卡面一致。
- 两栖登陆 / 大规模登陆受阵线空位限制，放不下时只放能放的部分。
